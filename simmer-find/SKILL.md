# 蓄力票扫描（simmer-find）

蓄力票的定义：**1 周到本月内一直在缓慢上涨**的股票。它有两种形态：

- A 型 · 回踩蓄力（大跌后横盘）：曾冲上过高点、有过人气（涨停/连板/大涨），随后经历一轮大跌，近期转入横盘——平台整理、不再创新低、重心缓升。横盘即蓄力，是再次爆发前的征兆；不是浅回踩不破关键位那种“强势整理”。
- B 型 · 缓涨蓄力：没有暴涨，靠自身强势沿均线小步慢涨，回调浅、量价健康。

前提条件（硬依赖）：**蓄力只有发生在强势板块里才有意义**。板块不是市场主线/强势方向时，个股很难维持缓涨趋势，回踩可能变成下跌。因此本 SKILL 第一步必须先用 $market-data 的板块行情榜（fetch_sector_boards）挖出当日强势板块、定出板块池，再进板块筛选；跳过这一步直接全市场找票 = 未按流程执行。

## 触发与前置

- 触发：用户请求“找蓄力票 / 缓慢上涨的票 / 回踩蓄力 / 抗跌慢牛 / 有没有在蓄力的票”，或需要为强势板块补充“没涨完但没爆发”的候选时。
- 前置（必须按顺序）：
  1. $market-data 可用——先取板块行情榜（fetch_sector_boards：板块代码、今日/5日/10日涨幅、上涨/下跌家数、领涨股、主力净流入）定出强势板块池，再用 fetch_sector_leaders 板块成分股榜、fetch_quote 个股日K/MA 下钻；
  2. 只读 ACCOUNT.md「板块权限」：读取主板/创业板/科创板/北交所是否开通、ST 是否允许交易；未提供或未确认时用保守默认（仅主板可交易、创业板/科创板/北交所未开通、ST 不交易）并标注“权限未提供，按默认处理”。不读取 MUST.md / NOTES.md / POSITION.md / stocks/；个人阈值（市值/换手/环境口径）只取用户请求中的说明，未说明则用本 SKILL 默认值并写进报告。
- 大盘环境：先经 $market-data 拉 sh000001 的日K与 MA20/MA60，判上升/震荡/下跌市，用于“抗跌适配”判断。
- 落盘：报告写入 report/蓄力票扫描/YYYY-MM-DD.md（report/ 与 report/蓄力票扫描/ 不存在则创建；同日再次运行覆盖更新并注明运行时间）。
- 交接：本 SKILL 只“发现+筛选+写观察建议”，不输出买卖信号；是否值得买转 $stock-analysis，观察建议写在报告里、不落盘（由用户自行盯），资金仓位走 $position-management。

## 默认筛选阈值（经验默认；用户请求说明优先）

| 检查项 | A 型·回踩蓄力 | B 型·缓涨蓄力 |
|---|---|---|
| 形态来源 | 曾冲上高点且有过人气：历史上曾涨停/连板或大波段上涨，随后经历一轮大跌（自高点默认回撤 ≥30%） | 无暴涨，沿 MA5/MA10 小步上行 |
| 当前形态 | 大跌后已转入横盘：平台整理、重心缓升、不再创新低 | 缓涨趋势本身，回调浅 |
| 近5日累计 | -3% ~ +6%（横盘内小幅波动） | 0% ~ +10%（无单日爆发） |
| 近10日累计 | -3% ~ +10%（横盘或微升，平台未破） | >0，且近10日最大回撤 ≤8% |
| 近20日累计 | 横盘重心缓升：0 ~ +15%（仍单边下跌创新低的不算） | +3% ~ +30%（3% 以下视为横盘，不算缓涨） |
| 位置 | 现价在低位横盘平台内：距平台内高点 ≤15%、不创新低；距历史高点已深度回撤 | 现价在 MA20 与 MA60 上方 |
| 人气/量能 | 历史人气需可核验（无法核实标“待核”）；横盘缩量、偶有温和放量试盘，换手 2%–15% | 上涨有量、回调缩量，换手 2%–15% |
| 剔除 | ST/退市、N/C 新股、当日涨停或涨幅 ≥7%、换手 >25%；仍在单边下跌未横盘、横盘破位创新低的也不算 | 同左 |

大盘适配（默认）：

- 上升市（指数在 MA20 上方且 MA20 上行或站上 MA60）：A、B 都按上述标准筛；
- 震荡市（指数围绕 MA20）：A 型保留“横盘未破位”的候选，B 型只保留近20日累计 >0、回撤浅的候选；
- 下跌市/指数在 MA20 下方：A 型要求横盘平台不破、近10日不创新低；B 型要求“抗跌”——近10日累计 ≥0，或个股近10日回撤 ≤ 指数近10日回撤 +3 个百分点，且未破 MA60；不符合的候选标注“环境不适配”并剔除。

## 流程

### 第一步：先取强势板块（不可跳过）

1. 经 $market-data 取当日板块行情榜：fetch_sector_boards.py --type industry --sort change --top 15 与 --type concept --sort change --top 15，再用 --sort gain5 --top 15 复核近 5 日延续性；记录每个板块：板块代码（BKxxxx）、类型（行业/概念）、今日/5日/10日涨幅、上涨/下跌家数、领涨股、主力净流入。
2. 按强势板块默认口径筛板块池（用户请求说明优先）：板块当日涨幅 >0 且近 5 日涨幅 >0 且上涨家数 ≥ 下跌家数 且主力净流入非明显流出；排序按「当日与近 5 日涨幅 × 资金」，取 ≤5 个（与涨停分布重叠的同一题材合并）。榜前但当日或近 5 日为负、宽度不过半、资金明显流出的板块不进板块池。
3. 没有板块满足口径（无明确强势方向）时：停止筛选，报告写明「今日无强势板块，蓄力票扫描不成立（蓄力必须依托强势板块）」，不硬找；板块数不足 5 个时按实际个数。

### 第二步：板块成分股初筛

对每个强势板块经 $market-data 拉板块成分股全量榜单（不按当日涨幅截断，否则会漏掉正在横盘的 A 型票；具体脚本与参数由 $market-data 决定），再按默认阈值快筛：

- 剔除：板块权限外的股票（按 ACCOUNT.md：主板 60/00、创业板 300/301、科创板 688/689、北交所 4/8/92；未开通板块即使形态合格也不处理）、ST/退市（ACCOUNT.md 标“允许”时才保留）、名称 N/C 开头新股、当日涨停或涨幅 ≥7%、换手 >25%（过热）；
- 保留：A 型候选（近5日 ≥ -3%、转入横盘不创新低）或 B 型候选（近5日 >0、近20日 >3%）、流通市值按用户说明（未给则不设限只标注）；
- 每板块保留 ≤6 只进入形态核验，其余进“备选名单”（报告附代码即可）。

### 第三步：大盘环境与个股形态核验

1. 大盘环境：经 $market-data 拉 sh000001 日K与 MA20/MA60，输出环境（上升/震荡/下跌）与指数近10日涨幅/回撤，作为抗跌基准。
2. 对初筛候选（每板块 ≤6、合计 ≤15）逐只经 $market-data 拉个股日K与资金流向；请求时说明需“JSON 完整 K”：B 型 60 根即可，A 型 120 根以上覆盖“冲高→大跌→横盘”完整过程（如 fetch_quote --days 120 --json，返回完整 N 根而非文本的最近 15 根）。按参考细则计算：近5/10/20日累计涨幅、距历史高点回撤、横盘平台区间与是否创新低、MA排列、近10日最大回撤、量能（横盘缩量或回调缩量）。
3. 分类判定：
   - A 型：历史曾人气冲高（需核验）→ 自高点深度回撤（默认 ≥30%）→ 已转入横盘（近20日平台整理/重心缓升/不创新低）；历史日K不足以核实“冲高→大跌”的标“待核”，不硬判；
   - B 型：缓涨（近20日 +3%–30%）+ MA5≥MA10≥MA20 + 回撤浅 + 上涨有量回调缩量；
   - 既不像 A 也不像 B 的（仍单边下跌未横盘、横盘破位创新低、无历史人气的“死横盘”、连板情绪票）→ 剔除并写原因。
4. 大盘适配复核（见默认阈值表），把“环境不适配”的候选剔除或降级到备选。

### 第四步：排序与产出

入选名单每板块 ≤3、全报告 ≤6 只，按“板块强度 × 形态健康度”排：

- 板块强度：板块今日/5日涨幅、上涨家数宽度、资金（来自第一步的板块行情榜）；
- 形态健康度：A 看横盘平台是否扎实（振幅收窄、不创新低、重心缓升），B 看回撤浅、量价顺；
- 每只附“为什么是蓄力票”的一句话依据（数字），以及类型 A/B。

### 第五步：报告落盘

1. 读 references/report-template.md，按模板骨架逐节填充：节名、表头、列顺序照抄，`{{...}}` 全部替换为真实数字或“未获取”；当天没有内容的小节保留标题并写“无”或“不适用”。
2. 「今日无强势板块」时只保留「前提与数据源」并写明“今日无强势板块，蓄力票扫描不成立（蓄力必须依托强势板块）”，其余小节写“不适用（无强势板块）”，不硬找。
3. 正文先写入 report/蓄力票扫描/YYYY-MM-DD.md（目录不存在则创建；同日再次运行覆盖更新并注明运行时间），再在回复中给摘要与文件位置。

## 报告格式（固定）

以 references/report-template.md 为骨架，节名、表头、列顺序照抄，不新增或调序；模板里的使用说明与填充示例不写进报告。不可省略的要求：

- 落盘 report/蓄力票扫描/YYYY-MM-DD.md（同日重跑覆盖更新并注明运行时间），结尾必须带“不构成投资建议”。
- 「前提与数据源」（强势板块与板块池、大盘环境、板块权限来源与剔除只数）必须在报告开头并写出来源；今日无强势板块时只保留该节并写明“蓄力票扫描不成立”，其余小节写“不适用（无强势板块）”，不硬找。
- 每只入选票都必须有环境适配依据（带数字，如“下跌市中指数近10日 -4.2%，该股 +1.8%”）与“继续跟踪条件”（A 型：放量突破平台上沿／跌破下沿；B 型：跌破 MA20 收不回）。
- 淘汰留痕：被剔除的代表性形态与原因（权限外、连板情绪票、单边下跌未横盘、横盘破位创新低、无历史人气的死横盘、环境不适配）逐行写清。

各节的内容规格、表头与填写示例见 references/report-template.md（第五步落盘前读）。

## 硬性规则

- 必须先取强势板块：报告必须引用 $market-data 板块行情榜给出的强势板块（板块代码、类型、今日/5日/10日涨幅、上涨/下跌家数、领涨股、主力净流入）与筛选口径；没有板块满足口径时不得进入筛选，写明原因结束。
- 蓄力必须依托强势板块：不在第一步板块池名单里的股票不入选，哪怕形态再好。
- 板块权限硬过滤：只处理 ACCOUNT.md「板块权限」已开通的板块；无法买入的板块（未开通创业板/科创板/北交所等）即使形态满分也不进入入选或备选，报告注明权限来源与剔除数量。
- 数据必须真实：涨幅、MA、回撤、量能、资金全部来自 $market-data 报告并标数据日期；缺数据标“未获取”，不脑补。
- 阈值透明：每条筛选都注明用的是哪档默认阈值；本 SKILL 除 ACCOUNT.md「板块权限」外不读取工作区文件，用户请求中说明的个人阈值优先；同一报告内不混口径。
- 区分形态：连板/主升末段不是蓄力；仍单边下跌、未进入横盘的票不是 A 型；横盘破位创新低=蓄力失败，不算 A 型；无历史人气的“死横盘”不算 A 型；近20日 <3% 的纯横盘也不等于 B 型缓涨。
- 抗跌要对比：下跌市里“抗跌”必须与大盘近10日涨跌/回撤对比出数字，不能只写“看起来没怎么跌”。
- 只发现不下单：本 SKILL 不给买卖信号、不写买点止损；买卖判断转 $stock-analysis → $position-management。
- 报告必落盘：先写 report/蓄力票扫描/YYYY-MM-DD.md，再回复摘要。
- 格式统一：报告按 references/report-template.md 的固定骨架输出，节名与表头不改写、不调序、不新增小节——「前提与数据源」（强势板块与板块池、大盘环境、板块权限）必须留在报告开头并写出来源；样本或板块缺失时保留小节标题写“无/不适用”，模板里的使用说明与填充示例不写进报告。
- 输出可视化：数字一律进表格；形态判定用「A 型/B 型 + 数字」短标记，启动与失效条件用「启动 → 价位 / 失效 → 价位」两段式，不用整段描述；状态用固定标记（入选/备选/剔除、环境适配/不适配）；不写散文式数字段，不用表情符号。
- 免责声明：报告结尾必须带“不构成投资建议”。
