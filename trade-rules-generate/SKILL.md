# 交易规则清单生成

## 触发与前置条件

- 触发：用户直接请求生成规则，或 stock-analysis 判定值得买/值得加仓后自动调用。
- 前置：工作区已初始化；本金优先取 ACCOUNT.md，缺失用默认值（5000元）并标注；实战教训优先从 NOTES.md 读取；个人交易风格与必守规则从 MUST.md 读取，生成的规则不得违背。
- 首次生成：stocks/<代码>/TRADE-RULES.md 不存在时创建；生成后自动调用 $position-management 确认仓位。
- 加仓追加：必须有 stock-analysis 的「值得加仓」结论、POSITION.md 中该股持仓、且 stocks/<代码>/TRADE-RULES.md 已存在；缺任一条件不追加，先说明缺什么。

## 流程

触发方式：用户直接请求，或 stock-analysis 判定值得买/值得加仓后自动调用。

1. 收集输入（缺省用默认值并说明）：
   - 本金（默认5000元，优先从 ACCOUNT.md 读取）
   - 单笔最大亏损预算（默认本金的2%）
   - 风险偏好：保守 / 稳健 / 激进（默认稳健）
   - 交易周期：短线（1-2周）/ 波段（1-3个月）（默认1-2周）
   - 是否有实盘教训（如滑点、追高、破位没走；优先从 NOTES.md 读取，再问用户），有则先翻译成规则
   - 个人交易风格与必守规则（从 MUST.md 读取；文件只有标题或缺失时，向用户确认是否需要补充）
2. 计算约束：
   - 单笔最大亏损金额 = 本金 × 预算%
   - 示例：本金5000、预算2% → 单笔最多亏100元
3. 生成六格清单（每格必须可执行、带数字）：
   - 选什么：基本面体检及格（PE不为负、看得懂）、不在避雷清单、波动可承受
   - 何时买：只在支撑位附近企稳或放量突破后回踩不破；不追箱体中部和上沿
   - 买多少：单笔最大亏损≤X元（本金Y%）
   - 错了怎么办：止损=支撑位下方；收盘跌破执行；跳空破位/暴跌日不等收盘，接受滑点尽快走
   - 对了怎么办：止盈=压力位附近一次全卖；时间止损=周期上限内不涨就走
   - 交易后：每日收盘5分钟检查；平仓复盘三问
4. 附：
   - 下单前六问（每格对应一问，缺一条不做）
   - 空仓期两件事：筛选观察名单、每日5分钟看盘
5. 输出 markdown 清单；数字用用户确认的值；结尾注明“不构成投资建议”。
6. 加仓场景（stock-analysis 结论为值得加仓后触发）：先确认 POSITION.md 有该股持仓且 stocks/<代码>/TRADE-RULES.md 已存在，缺任一条件不追加、说明缺什么；满足则在文件末尾**追加**「加仓规则 <日期>」区块（加仓价、止损、止盈、新增仓位、盈亏比），不覆盖、不删除历史规则；后续以最新规则为准，并自动调用 $position-management 确认仓位。

## 硬性规则

- 规则必须具体到数字：没有数字的规则不会被执行。
- 不替用户定数字：给出默认值与理由，由用户确认。
- 实战教训优先写入：用户有止损滑点/追高/破位经验时，先翻译成规则再补默认项。
- 更新=追加：加仓生成的规则以「加仓规则 <日期>」区块追加到 TRADE-RULES.md 末尾，历史规则保留备查；后续以最新规则为准。
