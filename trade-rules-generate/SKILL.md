# 交易规则清单生成

## 流程

1. 收集输入（缺省用默认值并说明）：
   - 本金（默认5000元）
   - 单笔最大亏损预算（默认本金的2%）
   - 风险偏好：保守 / 稳健 / 激进（默认稳健）
   - 交易周期：短线（1-2周）/ 波段（1-3个月）（默认1-2周）
   - 是否有实盘教训（如滑点、追高、破位没走），有则先翻译成规则
2. 计算约束：
   - 单笔最大亏损金额 = 本金 × 预算%
   - 示例：本金5000、预算2% → 单笔最多亏100元
   - 仓位上限默认：单只≤40%、总仓位≤70%（可按用户调整）
3. 生成六格清单（每格必须可执行、带数字）：
   - 选什么：基本面体检及格（PE不为负、看得懂）、不在避雷清单、波动可承受
   - 何时买：只在支撑位附近企稳或放量突破后回踩不破；不追箱体中部和上沿
   - 买多少：单笔最大亏损≤X元（本金Y%）；单只≤40%；总仓位≤70%
   - 错了怎么办：止损=支撑位下方；收盘跌破执行；跳空破位/暴跌日不等收盘，接受滑点尽快走
   - 对了怎么办：止盈=压力位附近一次全卖；时间止损=周期上限内不涨就走
   - 交易后：每日收盘5分钟检查；平仓复盘三问；模拟盘先练到“连续按计划执行”
4. 附：
   - 下单前六问（每格对应一问，缺一条不做）
   - 空仓期三件事：筛选观察名单、模拟盘验证规则、每日5分钟看盘
5. 输出 markdown 清单；数字用用户确认的值；结尾注明“教学演示，不构成投资建议”。

## 硬性规则

- 规则必须具体到数字：没有数字的规则不会被执行。
- 不替用户定数字：给出默认值与理由，由用户确认。
- 实战教训优先写入：用户有止损滑点/追高/破位经验时，先翻译成规则再补默认项。
