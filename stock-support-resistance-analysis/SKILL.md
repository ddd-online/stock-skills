# 支撑压力分析

## 流程

1. 确认标的，拉取数据：

   ```bash
   python scripts/fetch_quote.py <代码> --days 60
   ```

2. 找锚点（三种方法，重叠区域优先）：
   - 前期低点/高点：近2-4周的明显低点/高点；多次触及的价位可信度更高
   - 成交密集区：成交量集中的价位（量柱大的日子附近）
   - 均线/整数关口：MA20/MA60、整数价位（如20元、4.7元）
3. 判定区域（区域不是精确线）：
   - 支撑区：低点 + 均线叠合（如低点4.701与MA20 4.712）
   - 压力区：高点群（双高点比单高点更可信）
4. 评估有效性三因素：在这个区域停留时间长短、伴随量能大小、距离当前远近。
5. 输出：
   - 支撑区（1-2个，标依据：哪个低点/哪条均线/几次测试）
   - 压力区（分层：第一道最紧，第二道以上）
   - 当前价格位置：靠近支撑还是压力（距离%）
   - 角色互换提示：若已跌破/突破，旧位变新角色
   - 盈亏比参考：支撑买→压力卖 vs 现价追入（教学演示）
6. 数据日期标注；结尾“不构成投资建议”。

## 硬性规则

- 只输出真实数据推导的区域，不编造价位。
- 区域优先：说“4.70–4.71一带”而不是“支撑在4.70”。
- 假突破提醒：突破/跌破需配合放量与回踩确认，警惕“差一点又回来”。
