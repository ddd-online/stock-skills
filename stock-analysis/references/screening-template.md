# 个股体检五步模板

1. 买得起吗：一手金额=价格×100；按实际可用资产（=本金+总盈亏−累计支取）与当前现金算最多几手；板块权限（创业板/科创板有门槛）。
2. K线在讲什么：阴阳线、实体、上下影线、十字星；先定周期（日K/周K/60分钟K）。
3. 趋势在哪个周期：高低点方向；MA5/20/60 排列；多头/空头排列。
4. 风险像不像你：近期涨幅、振幅、估值（PE/PB）；满仓±10%能否接受。
5. 写下体检结论：一句话说清“赚不赚钱、贵不贵、风险在哪”。

结论示例：PE为负、PB 9.5、换手15%+、价格在MA60下方 → 基本面不及格，只可当技术面博弈，必须严格止损。

## 报告结构（证据→结论）

- 证据分节：基本面 / 技术面 / 支撑压力 / 风险 / 仓位匹配
- 结论放最后：建仓 / 加仓 / 减仓 / 空仓信号（观察为中间态）+ 硬伤或待观察条件
- 条件单参数（进池/等待/建仓信号时必出）：类型 / 触发价 / 委托限价 / 止损 / 止盈 / 手数上限 / 撤销条件，规则见 references/conditional-order.md
