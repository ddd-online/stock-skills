# 条件单参数设计（观察池买入策略）

条件单的意义：让交易软件在盘中自动盯价格触发，不依赖每日两次复盘。但**条件单只验证价格，验证不了量能/资金/收阳形态**，所以参数按「价格触发 + 触发后人工复核」两层设计。

## 什么时候给条件单

- 观察池标的（等待）与建仓信号标的：**必须输出条件单参数**，要素齐全（类型/触发价/委托限价/止损/止盈/手数上限/撤销条件）。
- 空仓信号、体检不及格：不进池，不给条件单。
- 以下情形**不设条件单**，并在报告中说明原因：
  - 一手风险超预算：（限价−止损）×100 > 单笔预算
  - 无既有触发条件支撑的价格位（不能为凑单现编买点）
  - 纯情绪高潮期（异常波动公告 / 龙虎榜 / 高位放量）
  - MUST 不买的情形：下跌趋势、纯题材无基本面、震荡箱体无方向（箱体票只可等突破型条件单）

## 参数设计规则

- 回踩买：触发价 = 支撑区上沿附近（如支撑区 11.0–11.1 → 触发 11.05–11.10），委托限价 = 触发价 + 0.05~0.15 滑点；止损 = 原预案止损（支撑区下沿下方）
- 突破买：触发价 = 压力位/前高上方 1%~2%（如 7.0 箱体上沿 → 触发 ≥7.05），委托限价 = 触发价 + 0.05~0.15；止损 = 原预案（跌回突破位下方）
- 止盈沿用原预案（第一压力位 → 第二压力位）
- 撤销条件：跌破支撑区下沿/突破位 → 撤销；触发日低开 >3% 开盘 2 分钟未收复昨收 → 放弃（MUST 铁律2）

## 手数上限公式（按 ACCOUNT.md 资金规则）

手数上限 = floor(单笔预算 ÷ ((委托限价 − 止损) × 100))

- 单笔预算默认 = 本金 × 2%（当前 114.56 元）；连亏 2 笔降档 = 本金 × 1%（57.28 元），手数减半
- 一手风险超过预算 → 不设条件单，等止损空间收窄或换更近买点
- 金额/批次最终由 $position-management 资金调度确认，本参考只给参数

## 触发后复核清单（条件单不替代确认）

1. 量能：触发时是否放量（当日量 vs 5 日均量）；缩量冲高回落 → 放弃
2. 换手：≥3% 才执行（MUST 铁律5）
3. 资金：盘后核对主力净流入方向；大幅流出 → 放弃
4. 形态：收盘是否收阳/站稳触发位；收阴破位 → 放弃
5. 开盘纪律：触发日低开 >3% 且开盘 2 分钟未收复昨收 → 放弃（MUST 铁律2）

## 使用纪律

- 条件单当日有效：每日早盘按最新收盘价复核触发价，收盘未触发次日重挂
- 触发后买入即挂止损/止盈条件单
- 突破型条件单触发时缩量或冲高回落 → 人工放弃
- 每日复盘报告条件单状态（触发/未触发/撤销/已执行），触发后按复核清单给出执行结论
