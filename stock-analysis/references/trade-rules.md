# 六格清单分析模板（不落盘）

stock-analysis 在建仓/加仓信号输出时用本模板完成六格清单分析，作为交接内容交给 $position-management，由其汇总进 stocks/<股票名称-股票代码>/STOCK-REVIEW.md「交易计划」；工作区不再生成 TRADE-RULES.md，本模板不写入任何文件。

## 六格清单（数字按用户确认值替换）

| 格子 | 规则 |
|---|---|
| 选什么 | ①基本面体检及格：PE不为负、看得懂 ②不在避雷清单 ③波动能承受 |
| 何时买 | 只在支撑位附近企稳买，或放量突破后回踩不破；不追箱体中部和上沿 |
| 买多少 | 单笔最大亏损≤100元（实际可用资产2%；实际可用资产=本金+总盈亏−累计支取） |
| 错了怎么办 | 止损=支撑位下方；收盘跌破执行；跳空破位/暴跌日不等收盘，接受滑点尽快走 |
| 对了怎么办 | 止盈=压力位附近，一次全卖；2周不涨就走 |
| 交易后 | 每日收盘检查；平仓复盘（事实→执行→判断→改进） |

## 下单前六问

1. 选什么：这只票体检及格了吗？
2. 何时买：现在的位置符合买点吗？
3. 买多少：这笔最多亏多少，倒推买几手？
4. 错了怎么办：止损和触发规则写下来了吗？
5. 对了怎么办：止盈和时间止损写下来了吗？
6. 交易后：日志模板准备好了吗？

缺一条就不做。

## 实战教训 → 规则

| 教训 | 规则 |
|---|---|
| 买在箱体中部 | 买点=支撑位企稳或突破回踩，不追中部 |
| 止损被跳空打穿，滑点44元 | 跳空破位不等收盘；接受滑点尽快成交 |
| PE为负还博弈 | 基本面体检不及格不碰；技术博弈更小仓位 |
| 暴跌日执行双止损 | 止损无条件执行 |

## 空仓期两件事

- 用清单筛选观察名单
- 每日收盘看盘练手感
