# 前5课基础速查（交易规则 · K线 · 趋势 · 量价 · 仓位止损）

适用：分析中需要解释基础概念（交易成本、K线、均线、量价、仓位）时读取。

## 第1课 交易规则与成本

| 项目 | 要点 |
|---|---|
| 最小单位 | 1手=100股，买入按100股整数倍申报 |
| T+1 | 当天买入最早下一个交易日才能卖出 |
| 涨跌幅 | 沪深主板±10%（ST同，2026年7月起）；创业板/科创板±20% |
| 交易时间 | 9:30–11:30、13:00–15:00；14:57–15:00收盘集合竞价 |
| 佣金 | 通常万2.5–万3，单笔最低5元（买卖双向） |
| 印花税 | 0.05%，仅卖出时单边征收 |
| 过户费 | 0.01‰，买卖双向 |
| 板块权限 | 创业板：日均资产≥10万+2年经验；科创板/北交所：日均≥50万+2年经验（小额本金开不了） |

## 第2课 K线

- 四要素：开盘价、收盘价、最高价、最低价
- 阳线（红）：收盘>开盘；阴线（绿）：收盘<开盘
- 实体：开盘价与收盘价之间，实体越长力量越强
- 影线：长上影=上方抛压重；长下影=下方有承接
- 十字星：开收接近，多空僵持
- 先定周期：日K/周K/60分钟K 含义不同

## 第3课 趋势与均线

- 三种趋势：上升（高低点抬高）、下降（高低点降低）、横盘（区间拉锯）
- 均线MA：过去N日收盘均值；MA5/10/20/60
- 金叉：短期均线上穿长期均线（偏多参考）；死叉：下穿（偏空参考）
- 多头排列：短均线在上、都向上、价格在均线上方（偏强）；空头排列反之
- 价格在MA20上方=短期偏强；价格在MA60下方=中期未转多

## 第4课 量价

- 放量：量明显放大=参与人多、分歧大；缩量：观望气氛
- 量价齐升：价涨量增=资金积极（高位出现要警惕）
- 放量滞涨：涨幅小/冲高回落+巨量=上方抛压、可能出货
- 放量大阴线：高位出现=警惕变盘
- 换手率：>15% 情绪主导、分歧巨大

## 第5课 仓位与止损

- 最大亏损预算：一笔交易前决定愿亏多少（新手默认本金2%）
- 仓位倒推：可买股数≈最大亏损÷（买入价−止损价）；单只≤40%、总仓位≤70%
- 止损：跌破预设价无条件卖，放在支撑位下方
- 止盈：压力位附近落袋；新手一次全卖
- 时间止损：周期内（如2周）不涨就走，给机会成本设上限
- 盈亏比：潜在盈利÷潜在亏损，理想>1，越高越值得
- 回本线：亏50%需涨100%才回本——亏损越深回本越难
