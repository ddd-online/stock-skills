# 基本面六数字速查

来源：深交所《基本面分析，发现价值之旅》、南方财经《股票入市指南》第十三/十八期、上交所投教《如何分析市价比率》。

| 数字 | 新手怎么理解 | 危险信号 |
|---|---|---|
| 营业收入 | 公司在不在长大（同比是否增长） | 连续下滑 |
| 净利润 | 扣成本费用税后真正赚的钱 | 为负=亏损 |
| 毛利率 | 生意好不好做，高=有定价权 | 长期很低或下滑 |
| 资产负债率 | 借的钱占总资产比例 | 过高（行业差异大，通常>70%警惕） |
| 市盈率PE | 按当前盈利几年回本 | 为负=亏损；远高于同行 |
| 市净率PB | 价格相对“家底”贵不贵 | 远高于同行/历史 |

## 三个比

- 和同行比（同行业公司之间）
- 和历史比（该公司过去几年）
- 和增长比（高增长可支撑较高PE；增长不及预期时会杀估值）

## 一句话判断

PE为负=公司当前不赚钱；PB很高+PE为负=价格主要靠情绪与资金，基本面体检不及格。

## 数据口径提醒

行情接口返回的 PE 可能是静态/动态/TTM 口径，且可能随财报更新变号（实测：同一只股票一日内从-152变为+100）。重大结论（尤其 PE 正负）建议用财报核实后再定性。

## 营收/净利润/毛利率怎么查

行情接口没有这三个指标，用财报接口脚本查询：

```bash
python scripts/fetch_fundamentals.py <代码>          # 默认最近4个报告期
python scripts/fetch_fundamentals.py <代码> --periods 8
```

脚本输出（东方财富数据中心公开接口）：报告期、营业总收入及同比、归母净利润及同比、销售毛利率、销售净利率、资产负债率、ROE。

怎么读：
- 营业收入：看同比增速——公司在不在长大；连续两个报告期下滑要警惕
- 净利润：看同比和绝对值——为负=亏损；增速比营收慢说明赚钱效率在变差
- 毛利率：看水平和趋势——高且稳=有定价权；持续下滑=竞争加剧
- 负债率：看绝对值——过高（行业不同，通常>70%）财务风险大
- 对比原则：和同行比、和历史比；同比只和去年同期比（一季报比一季报，年报比年报），不能拿一季报和年报直接比
- 报告期数值是累计值：一季报=1季度，中报=上半年，三季报=前三季度，年报=全年
