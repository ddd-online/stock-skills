# 持仓每日检查速查（收盘复盘第 3–5 步）

> 用于持仓检查模式：对 POSITION.md 中的每只持仓逐只输出，$stock-report 收盘版直接汇总进「三、收盘复盘」的第 3–5 步，不二次改写。
> 数据用收盘全天数据（午间调用用盘中数据并注明时段）。不预测涨跌，只写“如果……就……”。

## 收盘复盘输出格式（固定三段）

### 第三步 · 个股

- 日K与位置：开 {{开盘价}} / 高 {{最高价}} / 低 {{最低价}} / 收 {{收盘价}}（{{涨跌幅}}），{{形态一句（如“高开冲高回落长阴”“突破后缩量回踩收 MA5 上方”）}}；现价相对 MA5/MA10/MA20/MA60 {{之上/之下}}
- 对照规则：距止损 {{金额（%）}}、距止盈 {{金额（%）}}、时间止损 {{日期}}；触发判断 {{触发 / 未触发}}，如“收盘 7.21 > 止损 7.20 → 未触发，按计划持有”/“盘中最低 36.72 破 36.90 后收回 → 不触发”
- 买入理由：{{成立 / 部分成立 / 已破坏}}，{{依据}}；新信息：{{公告/新闻/大盘与行业变化，查不到标“未核实”}}；心态：{{有无冲动想改计划及原因}}

### 第四步 · 量价

- 量能：成交量 {{手}} / 换手 {{%}}，{{放量/缩量/平量}} {{上涨/下跌}}
- 翻译：{{放量上涨 = 真金白银承接，突破可信；放量下跌 = 有人大笔离场，警惕出货（高位放量触发铁律4：直接清仓）；缩量回调 = 卖压不大，上升结构里算健康；缩量上涨 = 跟风不足，涨得虚}}

### 第五步 · 明日预案

| 股票 | 9:25 看什么 | 触发条件 | 我的动作 | 不许做什么 |
|---|---|---|---|---|
| {{股票名}} | {{竞价是否低开 / 能否收复 {{价位}} 等}} | {{低开破 {{价位}} / 收复 {{价位}} / 反弹到 {{区间}} / 时间止损到期}} | {{开盘即走 / 按预案离场 / 继续持有}} | {{不临时挪止损、不追高、不加仓摊平、不找理由等反弹}} |

- 触发条件必须可检查（跌破某价 / 收复某价 / 低开破位），不许写“感觉”。
- 跳空破位/暴跌日不等收盘：9:25 竞价即执行；T+1 当天买入不能卖。
- 预案只引用用户已写规则（POSITION.md 触发规则、交易计划、MUST.md 禁区），不产生新建议；“不许做什么”写该股禁区。
- $stock-report 收盘版逐只汇总本输出为「三、收盘复盘」第 3–5 步。

## 触发规则

| 情形 | 判断 |
|---|---|
| 收盘价跌破止损 | 触发，离场 |
| 跳空低开直接跌破止损 / 暴跌日 | 不等收盘，破位即走 |
| 盘中插针（最低破、收盘守住） | 不触发 |

输出口径：只说“触发 / 未触发”，不预测涨跌；触发只给“建议平仓”结论与触发条件，实际卖出由用户在可交易时间执行。

## 记录位置（只追加）

- stocks/<股票名称-股票代码>/STOCK-REVIEW.md：在「每日检查」表追加一行，决定列含客观判断与“明日预案：…”一句话；交易计划节不改写，不创建文件。
- POSITION.md：更新该股持仓明细小节的现价与浮动盈亏（标注数据日期）；出现异动（接近/触发规则、建议平仓等）时在小节内追加一行“{{日期}} 备注：…”。
