# 个股全面分析（是否值得买）

原则：**基于真实数据、基于近期数据、证据先行、结论最后**。输出不构成投资建议。

## 流程

1. 确认标的：代码（sh/sz前缀，如 sh600410、sz002491、sh510300）与名称；确认是A股还是ETF。
2. 拉取真实数据：

   ```bash
   python scripts/fetch_quote.py <代码> --days 60
   python scripts/fetch_fundamentals.py <代码>
   ```

   行情或财报接口拿不到数据就明确说“数据获取失败”，不编造价格、PE、PB、营收或利润。
3. 证据收集，逐项填写（所有数字必须来自上一步数据，标注数据日期）：
   - 基本面：PE 正负与数值、PB（行情接口）；营收、净利润、毛利率、负债率（fetch_fundamentals.py，注意同比要和去年同期比）；与同行/历史比较；ETF 标注“不适用，看指数估值”。
   - 技术面：近期趋势（高低点方向、MA5/10/20/60 排列、价格相对 MA60 的位置）、量价（放量/缩量、高位放量滞涨/大阴线）。
   - 支撑压力：按“前期高低点、成交密集区、均线/整数关口”标注近期支撑区与压力区。
   - 风险：ST/退市、题材炒作特征、换手率与振幅是否剧烈；避雷清单逐条过。
   - 仓位匹配：一手金额=价格×100；按用户本金算可买几手；单笔最大亏损预算（默认本金2%）倒推仓位。
4. 证据汇总（一节一节列出数字）→ 最后写“结论”。
5. 结论三选一：
   - 值得买：证据全部通过，给交易计划要素（买点/止损/止盈/时间止损/仓位/盈亏比，教学演示）。
   - 观察：差什么条件写清楚（如“等回踩支撑企稳”）。
   - 不买：指出硬伤（如“PE为负+PB近10倍”“ST退市风险”），一句话说明。

## 输出格式（固定）

1. 标题 + 数据日期（如：通鼎互联（sz002491）分析 · 截至2026-08-19）
2. 证据：基本面 / 技术面 / 支撑压力 / 风险 / 仓位匹配
3. 结论（放最后）：一句话理由 + 硬伤或待观察条件
4. 结尾：“以上基于截至<日期>的真实数据，不构成投资建议，最终决定由用户作出。”

## 硬性规则

- 证据先行：先给可核验的数字，再下结论；禁止先有结论再找证据。
- 近期数据优先：只用最近3-6个月行情与最新估值；陈旧数据必须标注日期。
- 数据必须真实：脚本拉不到就报错，不猜测。
- 不替用户做决定：结论用框架（值得买/观察/不买），不承诺收益、不催单。
