# 涨停板查找判定细则

用途：limit-find 输出报告时的判定速查。所有阈值均为默认经验值，用户明确说明的个人规则优先；所有数字必须来自 $market-data 的真实报告并标注数据日期；不构成投资建议。

## 1. 常用口径

- 涨停/跌停/炸板池：东方财富涨停板专题（push2ex），涨停池不含 ST 与科创板。
- 封板率 = 今日涨停家数 /（今日涨停 + 今日炸板）×100%；炸板率 = 100% − 封板率。
- 晋级率 = 昨日涨停家数中今日继续涨停的数量 / 昨日涨停家数 ×100%。
- 一字板判定：当日行情 开 = 高 = 低 = 收（且涨幅为正），不是只看 9:25 封板。
- 连板统计“N天M板”：N 日内出现 M 次涨停（含当日），与“连续 N 板”不同，写报告时照抄不换算。

## 2. 情绪温度（涨停家数）

| 涨停家数（东财口径） | 标注 |
|---|---|
| ≥80 | 偏热 |
| 40–79 | 常态 |
| <40 | 偏冷 |

配合环比：涨停减少且封板率下降 → “热度回落（数字）”；涨停增加且封板率抬升 → “热度回升（数字）”。

## 3. 退潮/炸板潮判定（三信号）

同时出现以下两项及以上 → 标“情绪退潮迹象（数据判定）”：

1. 最高板数较昨日下降；
2. 晋级率较昨日下降（无昨日数据时按晋级率 <30% 视为偏低）；
3. 炸板率较昨日抬升。

炸板潮判定默认：炸板率 ≥35%，或（炸板家数 ≥15 且较昨日明显增多，如 +50% 以上）→ 有炸板潮/退潮迹象；否则无明显炸板潮。

## 4. 板块行合并与主线确认

“板块行”= 每日板块行情榜记录行。涨停复盘时把两类行并到一张表：

| 板块（代码） | 类型 | 今日% | 5日% | 10日% | 领涨股 | 主力净流入(亿) | 涨停家数 | 判定 |

- 涨停口径行：涨停股行业分布 Top（行业/概念）。
- 行情榜行：行业板块/概念板块的当日与近5日涨幅、领涨股、资金。

主线确认（默认）：涨停家数集中（≥3 家或占比前 3）∩ 板块当日与近5日涨幅为正 ∩ 主力净流入非明显流出 → 交集按涨停家数排序取 ≤3 个。

判定标签：

- 主线候选：三个口径交集；
- 仅榜前：板块榜靠前但涨停不集中；
- 退潮候选：昨日主线今日跌出榜/涨停消失/炸板集中在该板块；
- 无明确主线：交集为空，不硬凑。

## 5. 开盘与尾盘分类（板块强弱与分化）

样本是**昨日涨停股**（不是当日涨停股）。逐只两个分类，数字全部取 fetch_limit_up.py 文本第五节与 --json 的 yesterday_open_close / yesterday_performance.rows。

分类口径（固定）：

- 开盘分类：开盘涨幅 =（今开 − 昨收）÷ 昨收 ×100%，四舍五入到 0.01% 后 >0 → 高开，=0 → 平开，<0 → 低开；无行情记“-”。
- 尾盘状态：在当日涨停池 → 涨停；在当日跌停池 → 跌停；其余按涨跌幅正负 → 上涨 / 平 / 下跌。盘中运行取运行时刻最新价，收盘后即收盘价，报告中注明口径。
- 单只股票未取到行情时不参与分类，单独注明只数。

情绪是否足（默认，用户说明优先）：

| 分布特征 | 判定 |
|---|---|
| 高开占比 ≥50% 且尾盘上涨（含涨停）占比 ≥50% | 情绪足（高开且守得住） |
| 高开占比 ≥50% 但尾盘上涨（含涨停）占比 <40% | 高开低走，承接不足 |
| 低开占比 ≥50% 且尾盘上涨（含涨停）占比 <40% | 情绪弱 |

分板块强弱（默认）：

| 板块内昨日涨停股表现 | 判定 |
|---|---|
| 尾盘上涨（含涨停）占比 ≥60% 且无跌停 | 强势 |
| 尾盘上涨占比 40%–59% | 中性 |
| 尾盘上涨占比 <40%，或跌停 ≥2 家 | 弱势 |
| 板块样本 <3 家 | 样本不足（只写数字，不给强弱结论） |

板块内分化（默认）：

| 板块内形态 | 判定 |
|---|---|
| 同时有高开 ≥+3% 与尾盘下跌（含跌停） | 分化：板块内部不一致，点出代表个股（高开的、尾盘跌的） |
| 全部高开且无一尾盘下跌 | 一致偏强 |
| 低开为主，或多数尾盘下跌 | 一致偏弱 |

读法：板块强势 + 一致偏强说明该板块资金还在做；板块出现分化说明先行资金已在撤，同一板块里“有的高开有的砸”是退潮的早期形态，只记录不参与。

## 6. 分板块晋级与炸板（板块活跃度）

数字取 fetch_limit_up.py 文本第六节与 --json 的 industry_promotion，口径：

- 板数分档：一板 / 二板 / 三板 / 四板及以上（按当日涨停股的连板数分档）。
- 板块晋级率 = 该板块昨日涨停股今日继续涨停家数 ÷ 该板块昨日涨停家数 ×100%；分母为 0 记“-”。
- 板块炸板率 = 该板块今日炸板家数 ÷（该板块今日涨停家数 + 该板块今日炸板家数）×100%；分母为 0 记“-”。

板块活跃度（默认，用户说明优先）：

| 条件 | 标签 | 含义 |
|---|---|---|
| 晋级率 ≥30% 且炸板率 <35% 且今日涨停 ≥2 家 | 活跃 | 板块内有资金接力，可列入下一步深查 |
| 炸板率 ≥35%，或晋级率 <30% 且今日涨停家数少于昨日 | 转弱 | 追高容易接最后一棒，只看不动 |
| 昨日涨停 <3 家且今日涨停 <3 家 | 样本不足 | 家数太少，不给活跃度结论 |
| 其余 | 中性 | 无明确方向 |

板数结构读法：

| 结构 | 含义 |
|---|---|
| 一板多、无二板以上 | 只有扩散没有高度，接力资金没进来 |
| 出现三板及以上 | 板块有高度，高度由哪只票撑着要写清（板数 + 个股） |
| 涨停家数增加但炸板率同步抬升 | 分歧加大，活跃度标签按炸板率优先落“转弱” |

用途与边界：这一节是给 $stock-analysis 深查板块内个股的筛选，只给数字与标签；不写买入动作、不预测次日。

## 7. 阵型四态（最近五次报告汇总）

单日数字只是体温，五份报告连着看才是阵型。样本取自 report/涨停板复盘/ 下最近的五份报告（当日 + 之前四次）；不足五份时按实际份数写并注明样本天数。

| 状态 | 特征 | 含义 |
|---|---|---|
| 高度打开 | 最高板连续抬高（如 6 板→7 板→8 板），晋级率回升到 30% 以上 | 情绪上升期；仍是高风险区，但接力有钱赚 |
| 轮动期 | 最高板卡在 3–5 板打不开，晋级率持续低于 30%，首板多而分散 | 打板胜率最低的一态 |
| 分歧期 | 高度持平、炸板率达到或超过 35%、跌停家数两位数 | 方向未选完，只观察 |
| 崩塌/退潮期 | 最高板天地板或连续跌停；或跌停家数 ≥ 20 家**且** 跌停家数 ≥ 涨停家数的三分之一（两个条件同时满足，只有比例达标不算） | 不参与，等新一轮启动 |

判断顺序固定三步：**先看最高板有没有抬升 → 再看晋级率有没有回到 30% 以上 → 最后看炸板率**。第一步没做到，后两步好看也只算轮动。

“崩塌·退潮期”的下限（避免小样本误判）：跌停家数 ≥ 20 家 **且** 跌停 ≥ 涨停家数的三分之一，两个条件同时满足才成立；只有比例达标（例如涨停 15 家、跌停 6 家）按“分歧期”处理——6 家跌停撑不起“崩塌”。最高板天地板或连续跌停不受该下限约束，单条即可落崩塌。

**结构说明（阵型标签后必须紧跟一行，缺了视为不合格）**：

| 写什么 | 数据来源 | 例 |
|---|---|---|
| 崩在哪 | 跌停股行业分布（家数）+ 代表个股 | 一般零售 6 家跌停（百大集团、中央商场、国光连锁、南宁百货）、出版龙版传媒、种植业敦煌种业 |
| 抬在哪 | 高标梯队与最高板所在行业、连板数 | 电力闽东电力 5 板、元件澳弘电子 3 板、塑料双星新材 3 板 |
| 定型一句 | 上面两项合起来 | 老题材崩塌 + 局部高度抬升 |

只写“崩塌·退潮期”而不写结构，会让读的人以为全市场都在崩，而当天可能仍有票在创连板新高；只写“局部高度抬升”而不写崩塌面，又会低估退潮范围。

五次报告汇总表（写进报告的「阵型判定」一节）：

| 数据日期 | 涨停家数 | 跌停家数 | 炸板率 | 最高板 | 晋级率 | 单日态 |

- 四项数字取自各报告的「数据概览」「连板高度与最高板」「昨日涨停今日表现」，缺项写“未获取”，不脑补；
- 单日态：给每份报告一个暂定标签（高度打开/轮动期/分歧期/崩塌·退潮期），用来看走势是连贯还是反复横跳；
- 持续天数：在汇总表里数同一阵型连续出现的份数；
- 只判定当前位置，不推演下一日的阵型。
