# 涨停板复盘报告模板（limit-find）

> 用途：limit-find 生成 report/涨停板复盘/YYYY-MM-DD.md 的固定骨架。节名、表头、列顺序照抄不改写、不调序——次日 $limit-judge 按固定节名取数（「涨停全名单（供次日竞价评估）」「连板高度与最高板」「数据概览」「昨日涨停今日表现」「当日主线板块（板块行合并表）」「阵型判定（最近五次报告汇总）」），改名或调序会让下游取不到样本。

## 使用说明（生成报告前删除本节）

- 数据来源：全部经 $market-data 获取（对照表见文末），不自行取数、不复制取数实现。
- `{{...}}` 为待填字段，一律替换为真实数字或「未获取」；接口拿不到就写「未获取」，不填 0、不脑补。
- 当天没有内容的行直接删掉，不留空行；涨停全名单是例外——当日全部涨停股（含首板）逐行列出，不省略。
- 所有数字标数据日期；盘中运行在标题与概览写「盘中口径」，收盘后写「收盘口径」。
- 标题行的「运行时间」写本次实际运行时刻 HH:MM，同日再次运行覆盖更新。
- 模板中的「附：填充示例」只供对照格式，不写进报告；本使用说明节也不写进报告。
- 报告正文从标题行开始，结尾免责声明固定保留。
- 「阵型判定」节必须带「昨日阵型确认」子块（按昨日标签取的检验项 + 结论 + 动作提示 + 四格记账行 + 强标签延续率）：昨日标签照抄上一份报告、一个字都不改，用今日数据判分；**检验项跟着昨日标签走，不能拿「高度打开」的三项去套轮动期/分歧期/崩塌·退潮期**，口径见 references/formation-followup-cards.md。
- 「昨日阵型确认」的检验项行数按昨日标签增减：高度打开 3 项（空间板 / 晋级率 / 炸板率与跌停），轮动期 2 项（有无新高标 / 有无崩塌），分歧期 2 项（空间板收复 / 炸板与跌停收敛），崩塌·退潮期 2 项（跌停收敛 / 空间板止跌）；表头固定为「检验项（按昨日标签，固定顺序）| 今日数字 | 判分」。
