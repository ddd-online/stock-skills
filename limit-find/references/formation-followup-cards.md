# 阵型次日检验卡（limit-find）

用途：limit-find 报告「阵型判定」节里「昨日阵型确认」子块的判分依据。三项固定确认字段（空间板 / 晋级率 / 炸板率与跌停）是给「高度打开」配的判据；拿它去检验轮动期、分歧期、崩塌·退潮期，会把正确的判断判成错。**判据必须跟着昨日标签走。** 所有数字必须来自 $market-data 的真实行情并标数据日期；不构成投资建议。

## 1. 判据跟着昨天的标签走

同一个问题——「昨天这个判断，今天还成立吗」——四种标签的检验方式不一样，顺序固定：

| 昨日标签 | 今天检验什么（固定顺序） |
|---|---|
| 高度打开 | ① 空间板有没有续板 ② 晋级率有没有守住 30% ③ 炸板率与跌停 |
| 轮动期 | ① 有没有出现新高的高标（最高板抬升） ② 有没有崩塌（跌停潮） |
| 分歧期 | ① 空间板有没有收复 ② 跌停与炸板有没有同时收敛 |
| 崩塌·退潮期 | ① 跌停家数有没有收敛 ② 空间板有没有止跌 |

用「高度打开」的三项去检验「轮动期」，几乎必然得出「未确认」——轮动期的定义本来就是「没有抬升、没有崩塌」，判据与对象错配，就会给正确的判断记上错的分。手边只有一套判据时，先看昨天的标签是什么，再去取对应的检验卡。

## 2. 四张检验卡

| 昨日标签 | 延续（对） | 切换（另记） | 失效（错） |
|---|---|---|---|
| 高度打开 | 空间板续板（或高开不破前收）且晋级率 ≥30% | 空间板未续但未崩，晋级率 15%–30% | 空间板崩（跌停 / 跌停附近开盘 / 收阴 ≥5%）或晋级率 <15% |
| 轮动期 | 今日仍无新高标、无崩塌（即仍为轮动期） | 最高板抬升且晋级率 ≥30%（升级为高度打开）；或跌停回到两位数（转为分歧） | 跌停 ≥20 家，或跌停 ≥ 涨停家数的三分之一（跌入崩塌） |
| 分歧期 | 炸板率与跌停同时收敛（转回轮动） | 维持分歧；或直接升级为高度打开 | 跌停家数扩大、出现成片崩塌 |
| 崩塌·退潮期 | 跌停家数明显收敛、空间板止跌（转分歧或轮动） | 继续震荡，既不修复也不恶化 | 跌停家数再创新高 |

判分口径（与各卡的上表一致）：

- 高度打开：① 空间板继续涨停，或高开且不破前收 = 好；跌停 / 跌停附近开盘 / 收阴 ≥5% = 坏且一票否决（直接判失效，后两项不用看）；两者都不满足 = 中性。② 晋级率 ≥30% = 好；<15% = 坏；15%–30% = 中性。③ 炸板率 <35% 且跌停未成片 = 好；炸板率 ≥35% 或跌停家数两位数 = 坏。
- 轮动期：最高板抬升（新高标出现）或跌停回到两位数 = 切换，写明切到哪一态；跌停 ≥20 家或跌停 ≥ 涨停家数的三分之一 = 失效；两者都没有 = 延续。
- 分歧期：炸板率与跌停同时收敛 = 延续（转回轮动，在今日标签里写轮动期）；两者都不动 = 切换前的维持（写「维持分歧」）；跌停扩大成片 = 失效。
- 崩塌·退潮期：跌停明显收敛且空间板止跌 = 延续（在今日标签里写轮动期或分歧期）；既不修复也不恶化 = 切换前的中继（写「震荡维持」）；跌停再创新高 = 失效。

## 3. 对错怎么记：中性标签不计对错

| 标签类型 | 标签 | 记录方式 |
|---|---|---|
| 有方向的标签 | 高度打开、崩塌·退潮期 | 记对错：次日沿用同一标签 = 对；换标签 = 错 |
| 中性标签 | 轮动期、分歧期 | 不记对错，只记「延续 N 天 / 今天切换」；用来观察市场节奏 |

每日一行四格：**昨日标签 / 今日标签 / 变化类型（延续・切换・失效）/ 是否计入对错**。

- 强标签延续率 = 高度打开或崩塌·退潮期之后次日仍同标签的次数 ÷ 该类标签总次数（这才是「我的判断准不准」）。
- 切换速度 = 平均几天换一次标签（这衡量市场节奏，不衡量你）。
- 只有已有次日检验记录的标签才进统计，之前没留检验行的标签不事后补判——补判等于事后记账。

为什么这样分：「高度打开」和「崩塌·退潮期」是要动仓位动作的标签，判错了代价高，所以考它的延续率；「轮动期」是默认状态，每次延续都在预期内，记对错会虚增胜率，也会把正确的判断判成错的。

## 4. 动作对照

| 昨日标签 | 今日延续 | 今日切换 | 今日失效 |
|---|---|---|---|
| 高度打开 | 可进入买点评估（仍受 $stock-analysis 的前置条件约束） | 降级为只跟踪、不接力 | 当日不接板，相关票移出观察池 |
| 崩塌·退潮期 | 继续空仓、只做复盘 | 可开始建观察池（不是买） | 崩塌再恶化：继续空仓，不做任何反手 |
| 轮动期 / 分歧期 | 维持观察，等强标签出现 | 按切换后的新标签走动作 | 按崩塌处理：移出、空仓、复盘 |

动作只是纪律提示，不下单；要落到个股买卖走 $stock-analysis → $position-management。

## 5. 实例修正（09-16 ~ 09-18）

| 前一日标签 | 今日标签 | 变化类型 | 计入对错 |
|---|---|---|---|
| 高度打开（09-16） | 轮动期（09-17） | 切换 | 错：强标签未延续（09-17 空间板闽东电力断板 −2.76%、晋级率 10.1%） |
| 轮动期（09-17） | 轮动期（09-18） | 延续 | 不计对错（中性标签） |

按这个口径重算：强标签 1 次（09-16 高度打开），延续 0 次，强标签延续率 0%；轮动期自 09-17 起已持续 2 个交易日（09-17 → 09-18 记「延续 1 天」），不进对错分母。

旧口径的错误示范（09-18 报告）：昨日标签是轮动期，却用「① 空间板续板 ② 晋级率 ≥30% ③ 炸板率」三项去检验——09-18 空间板未续板（中性）、晋级率 25.5%（中性），于是把「今日仍无新高标、无崩塌」的正确延续写成了「未确认」，计入统计后判成「错」。

参考数据（09-18）：澳弘电子（09-17 的空间板，5 板）开 49.00、最高 50.62、收 47.40（−2.79%）未续板；涨停 78 家（47→78）、跌停 0 家、炸板率 24.3%（29.9%→24.3%）、晋级率 25.5%（10.1%→25.5%）；最高板 4 板 华瓷股份、锡华科技。

## 6. 纪律：四个不能犯的错

1. 拿一套判据套所有标签（把「高度打开」的三项用于轮动期、分歧期、崩塌·退潮期）——判据错配，会把正确的判断判成错，也会让中性标签的延续虚增胜率。
2. 事后把昨天的标签改掉（09-16 原样留着，在 09-17 写「失效」，不要回头改成「脉冲」之类）——改了等于没有赌注。
3. 把当日态当明日计划（09-16 判「高度打开」，09-17 最高板断板、晋级率 10.1%——标签没写错，拿它当发令枪才是错）。
4. 用「龙头还封着板」给板块壮胆（09-17 元件：澳弘电子 5 板封住，可板块主力净流出、涨停家数 4→1，两负）——龙头是龙头，板块是板块。

以上为经验性判定框架，无官方背书；与用户明确说明的个人规则冲突时以用户规则为准。所有分析不构成投资建议，股市有风险，投资需谨慎。
