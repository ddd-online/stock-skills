# 竞价读法细则

用途：judge-limit 填表、判定接力意愿与阵型态时的速查。所有阈值都是默认经验值，用户明确说明的个人规则优先；所有数字必须来自 $market-data 的真实报告并标注数据日期与行情时间；不构成投资建议。

## 1. 竞价三段与数据可信度

| 时段 | 规则 | 读法 |
|---|---|---|
| 9:15–9:20 | 可挂单、可撤单 | 表演区：挂大额买单制造抢筹假象，可能在 9:19 前撤掉，不作为依据 |
| 9:20–9:25 | 可挂单、不可撤单 | 真实意愿区：挂进来就撤不掉，只能成交或排队 |
| 9:25 | 撮合，产生开盘价与竞价成交量 | 每天第一份硬数据：开盘价 + 竞价成交额 |
| 9:25–9:30 | 不接受申报、不撮合 | 五分钟冷静期：用来算数字，不用来下单 |

附注：竞价里挂涨停买单不等于以涨停价成交。开盘价低于涨停价时，成交价是开盘价。

## 2. 三个数字的口径与经验区间

| 数字 | 口径 | 经验区间 |
|---|---|---|
| 高开幅度 | （今开 − 昨收）÷ 昨收 × 100% | ≥ +3% 说明昨日强势被认账；平开/低开说明昨日买入的资金今天想走 |
| 竞价量占比 | **竞价成交额 ÷ 昨日全天成交额 × 100%** | 3%–8% 活跃；>15% 警惕（可能借高开出货）；<1% 无人关心 |
| 集体分布 | 昨日涨停那一整批的高开/低开家数与平均高开幅度 | 单只票是噪音，整批分布才是赚钱效应的读数 |

竞价量占比是打板者最该盯的第二个数字：

- 温和放大（3%–8%）配合温和高开（+2%–+5%）→ 抢筹有序；
- 突然放巨量（>15%）且高开幅度很大 → 高开出货嫌疑；
- 占比很低（<1%）→ 市场不关心这只票，昨天买入的人没有对手盘。

## 3. 好接力 / 坏接力对照

| 信号 | 偏“好接力” | 偏“坏接力” |
|---|---|---|
| 昨日涨停股开盘分布 | 高开家数明显多于低开 | 低开家数占多数 |
| 平均高开幅度 | 温和高开 +2% ~ +5% | 平均低开，或极端高开（> +8%） |
| 竞价量 | 温和放大 | 突然放巨量（高开出货嫌疑） |
| 昨日最高板今日表现 | 高开或维持强势 | 低开、打不开、直接闷杀 |
| 炸板率（来自涨停板复盘报告） | 低于 25% | 达到或超过 35% |

判定接力意愿（默认口径，用户可覆盖）：

- **强**：高开家数 ≥ 样本 60%，且平均高开落在 +2% ~ +5%，且最高板未低开；
- **一般**：高开家数略多于低开，或平均高开在 0 ~ +2% 之间；
- **弱**：低开家数占多数，或平均高开 < 0，或平均高开 > +8%（极端高开同样危险）。

对照项全部为默认经验值：三格里两格偏坏 → 结论写"只观察"，即使平均高开是正的。

## 4. 阵型四态

| 状态 | 特征 | 含义 |
|---|---|---|
| 高度打开 | 最高板连续抬高（如 6 板→7 板→8 板），晋级率回升到 30% 以上 | 情绪上升期；仍是高风险区，但接力有钱赚 |
| 轮动期 | 最高板卡在 3–5 板打不开，晋级率持续低于 30%，首板多而分散 | 打板胜率最低的一态 |
| 分歧期 | 高度持平、炸板率达到或超过 35%、跌停家数两位数 | 方向未选完，只观察 |
| 崩塌/退潮期 | 最高板天地板或连续跌停，跌停家数达到涨停家数的三分之一以上 | 不参与，等新一轮启动 |

判断顺序固定三步：**先看最高板有没有抬升 → 再看晋级率有没有回到 30% 以上 → 最后看炸板率**。第一步没做到，后两步好看也只算轮动。

## 5. 最高板检查清单（硬规则执行）

1. 取报告中的昨日最高板代码，放进本次竞价清单（保证能被检查）；
2. 看它今天的开盘：高开、平开、低开、还是竞价涨停开；
3. 看它今天的最低价是否触及跌停价、最高价是否触及涨停价；
4. **只要出现"开盘涨停价、收盘/现价跌停价"式的天地板，或任何形式的跌停 → 当天不做任何打板动作，只观察**（写进报告首行与结论）；
5. 一字板打开的窗口以秒计：竞价涨停开但随后被砸开的标的列"高危"，不做第一波。

## 6. 常见错误

- 只填单只观察票、不看整批分布 —— 单只票的竞价是噪音；
- 用 9:20 之前的挂单判断意愿 —— 那段可以撤单；
- 9:30 之后才运行，却把全天成交额当成竞价成交额 —— 占比会严重虚高，必须标"非竞价口径"；
- 看到高开就当作可以打板 —— 高开幅度与竞价量占比要一起看，极端高开配巨量反而危险；
- 最高板已经天地板/跌停，还按其他指标"找机会" —— 硬规则优先，当天只观察。
