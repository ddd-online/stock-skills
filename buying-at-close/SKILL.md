# 尾盘买入法审视（buying-at-close）

尾盘买入法：等当天走势基本定型（14:30 之后）再决定，赚的是次日溢价，风险是次日低开。T+1 下买入当日无法止损，所以**买入前必须把次日止损止盈规则写好**——这份规则比买入本身更重要。

## 触发与前置条件

- 触发：用户请求“尾盘买什么 / 尾盘买入审视 / 收盘前选股 / 看看今天有没有尾盘票”，或约定时间（交易日 14:30 后）运行。
- 前置：工作区已初始化（ACCOUNT.md / POSITION.md / MUST.md / stocks/）；$market-data 可用。
- 时间窗口（本 SKILL 的硬边界）：
  - 14:30 前：只看不动，最多输出“预审清单”，不给买入结论；
  - 14:45–14:55：确认信号并输出结论的窗口；
  - 14:55 后：不新建买入建议（宁错过，不追尾盘急拉）；
  - 收盘后运行：按当日结果做“模拟复盘 / 次日预案”，明确标注今日已不可买。
- 依赖文件：MUST.md（「尾盘买入法执行规则」节 + 其他个人规则）、ACCOUNT.md（资金规则：实际可用资产口径、现金红线、单笔预算、当前档位）、POSITION.md（已有持仓：避免重复、受总仓位约束）、NOTES.md（教训准则）。
- 交接：买入结论 → 次日/资金执行由用户决定；建仓与资金调度走 $position-management，次日持仓检查走 $stock-review；本 SKILL 不下单。

## 第一步：检查 MUST.md「尾盘买入法执行规则」节（每次必做）

1. 读取工作区 MUST.md，查找标题含「尾盘买入法执行规则」的节（`###` 或 `##` 均可，按文件既有层级习惯）。
2. 不存在 → 在 MUST.md **末尾**追加一节，并把本 SKILL 的关键条件与默认阈值写入其中（保留全部既有内容、UTF-8 编码；内容为可修订默认值，见「内置默认规则」）：

   ```markdown
   ### 尾盘买入法执行规则

   - 时间：14:30 前只看不动；14:45–14:55 确认才下单；14:55 后不追；尾盘几分钟变盘风险大，宁可错过
   - 换手率：默认 5% < 换手 < 30% 才进入候选；换手 >15% 视为情绪票降级或放弃
   - 价格：只在关键位挂单（支撑企稳 / 突破回踩），不追尾盘急拉；没成交不撤单改价追高
   - 仓位：普通票 ≤30%、情绪票 ≤10%；单笔亏损预算 ≤ 实际可用资产 ×2%（降档期 1%）；当日尾盘总仓位 ≤70%
   - 市场：下跌市（指数收在 MA20 下方）只模拟不实盘；震荡市防守小仓；上升市正常档
   - 次日：9:25 看集合竞价；止损提前写；1–3 日内处理；持仓理由（次日溢价）消失就卖
   ```

3. 该节存在但没有可执行内容（仅标题/空行）→ 同样补入上述默认条件与阈值（不覆盖该节以外的 MUST 内容）。
4. 该节已有规则 → 以它为最高优先级执行，不写入、不覆盖；与 MUST.md 其他节冲突时按「尾盘买入法执行规则 > 其他 MUST > NOTES.md」处理，并在报告中注明采用了哪条用户规则。
5. 处理结果写入报告：标注“MUST 尾盘节已新建并写入默认条件（可修订）”/“既有空节已补默认条件”/“按 MUST 既有规则执行”。

## 流程

1. 读取工作区上下文：MUST.md、ACCOUNT.md（本金/现金/总盈亏/累计支取/实际可用资产/资金规则）、POSITION.md、NOTES.md；执行第一步的 MUST 节检查。
2. 确认当前时间与交易状态：非交易日 / 非交易时段按「触发与前置条件」处理，交易日 14:30 前只出预审清单。
3. 拉取大盘状态（判断市场档位）：
   - 调用 $market-data 获取上证指数与创业板指的大盘行情（要求含 MA20/MA60 与量能；具体脚本与参数由 $market-data 负责，本 SKILL 不包含执行命令）
   - 记录：现价、涨跌、MA20/MA60、量能；结合 ACCOUNT.md「资金规则 · 当前档位」给出市场状态：
     - 上升市（指数在 MA20 上方且均线上行）→ 正常档，可执行；
     - 震荡市（围绕 MA20 纠缠）→ 防守档，小仓；
     - 下跌市（收盘在 MA20 下方）→ 观望档，禁止实盘尾盘买入，只出模拟练习清单；
     - MUST「尾盘买入法执行规则」对档位有明确定义时以 MUST 为准。
4. 拉取强势股榜单：
   - 调用 $market-data 获取强势股榜单，并在请求中说明口径：按涨幅/活跃度排序的前 20 档、默认沪深 A 股并剔除 ST/风险警示、换手率默认 5%–30% 区间；需要板块或放宽范围时在请求中注明（实现与参数由 $market-data 决定）。
5. 快筛（用榜单 3 行以内数据即可排除）：
   - 剔除：ST/退市/风险警示（榜单请求已剔除）、当日一字涨停封死买不进、换手率不在默认区间 5%–30%（榜单请求已按 5%–30% 换手过滤；MUST 尾盘节另有阈值时以 MUST 为准）；
   - 标注：名字 N/C 开头的新股（上市 ≤5 日、无涨跌幅限制）为高风险，默认不进入买入候选；
   - 快筛后保留 ≤5 只进入细审；不足 1 只 → 报告“今日无合格尾盘票”，说明卡在哪条。
6. 细审（对每只候选调用 $market-data 拉真实数据）：
   - 行情（近 60 日价格/MA/量/换手/振幅）、资金流向（主力净流入，配合量价判断）、必要时近期公告与新闻（事件/公告逻辑证伪）；
   - 只向 $market-data 说明要哪些数据，具体脚本与参数由 $market-data 决定，本 SKILL 不包含执行命令。
   - 按下表「尾盘六问」逐项生成审视卡，每一项给“过/不过 + 依据数字”：
   - 另将 MUST.md 其他规则（如“二买三不买”“短线五条”）逐条对照，任何一条不过就不是“今天的尾盘票”。

   | # | 检查 | 标准（过 / 不过） |
   |---|---|---|
   | 1 | 体检及格 | PE 不为负 / 看得懂 / 不在避雷清单；换手率默认须在 5%–30%，>15% 情绪票降级或放弃（MUST 允许情绪博弈时按情绪票 ≤10% 处理） |
   | 2 | 趋势位置 | 多头排列或回踩均线企稳；下降趋势不接 |
   | 3 | 量价 | 当日缩量回踩或尾盘放量上涨；放量滞涨 / 大阴线排除 |
   | 4 | 支撑压力 | 买点=支撑区企稳或放量突破关键压力后回踩；写出参考支撑/压力价位 |
   | 5 | 市场状态 | 与第 3 步档位一致；下跌市不实盘 |
   | 6 | 尾盘三条约束 | 14:45–14:55 下单 / 关键位挂单不追急拉 / 仓位≤短线博弈档 |
7. 输出「尾盘买入审视报告」（格式固定）：
   1. 标题 + 日期与运行时间（如：尾盘买入审视 · 2026-09-02 14:50）
   2. 市场状态与档位（含 MUST 尾盘节状态：有规则（按既有）/原空节已补默认/已新建默认）
   3. 强势股榜单摘要（来源榜单 + 过滤口径）
   4. 逐只审视表（代码/名称/现价/形态/六问结果/MUST 检查 → 结论）
   5. 结论汇总：买入候选（≤2 只，按优先级排序）/ 全部不买（一句话理由）
   6. 给「买入」结论的每只股票输出「次日止损止盈规则卡」（见下）
   7. 结尾：“以上基于截至<日期>的真实数据，不构成投资建议，最终决定由用户作出。”
8. 买入候选同时给下单要素：买点（关键位挂单价）、止损、止盈、时间止损、手数上限（单笔预算 ÷ ((委托限价−止损)×100)，预算按 ACCOUNT.md 资金规则：实际可用资产 ×2%，降档期 1%）；执行金额与批次由 $position-management 复核确认。

## 次日止损止盈规则卡（给「买入」结论时必出）

| 项 | 规则 |
|---|---|
| 止损价 | 支撑区下沿 − 缓冲（0.5%–1%），写具体价位；买入前必须写好（T+1 当日无法止损） |
| 止损触发 | 次日低开跌破止损 → 开盘即走不等反弹；盘中跌破 → 收盘破位执行 / 破位即走按 MUST 与该股 STOCK-REVIEW.md 交易计划执行；跳空破位不等收盘 |
| 止盈 | 第一压力位附近；次日冲高滞涨（放量不封板 / 冲高回落）即走 |
| 时间止损 | 1–3 日内处理，不恋战；持仓理由（次日溢价）消失就卖，不养成“价值投资” |
| 9:25 集合竞价 | 先看竞价：高开冲高→观察是否滞涨；低开跌破止损→开盘即走；高开低走→按纪律处理 |
| 交接 | 次日按 $stock-review 检查；卖出后把卖出价/手数告知 $position-management 完成平仓结算 |

## 内置默认规则（新建/补齐 MUST 尾盘节时写入的内容；用户可自行修订）

- 时间：14:30 前只看不动；14:45–14:55 确认才下单；尾盘几分钟变盘风险大，宁可错过。
- 价格：只在关键位挂单（支撑企稳 / 突破回踩），不追尾盘急拉；没成交不撤单改价追高。
- 换手率：默认 5% < 换手 < 30% 才进入候选；换手 >15% 视为情绪票，降级（≤10%）或放弃。
- 仓位：短线博弈档——普通票 ≤30%、情绪票 ≤10%；单笔亏损预算 ≤ 实际可用资产 ×2%（降档期 1%，以 ACCOUNT.md 资金规则为准）；当日尾盘总仓位 ≤70%。
- 市场：指数收盘在 MA20 下方 = 下跌市（观望，只模拟）；围绕 MA20 = 震荡市（防守小仓）；MA20 上方且均线上行 = 上升市（正常档）。
- 次日：9:25 看竞价；止损提前写；1–3 日处理完；不接受“明天再说”。

## 硬性规则

- 数据必须真实：$market-data 拉不到就明确报错，不编造现价/量能/资金/形态。
- 一条过滤不过就不买；形态只是观察清单，不是买入保证。
- 时间一到即收手：14:55 后不新建买入建议，不追尾盘急拉。
- 下跌市 / 观望档只出模拟练习清单，除非 MUST「尾盘买入法执行规则」明确允许实盘。
- 只给结论不下单：实际买卖由用户在可交易时间执行；建仓执行与资金调度转 $position-management。
- 持仓理由只在次日溢价：理由消失就卖。
- 输出必须带“不构成投资建议”与数据日期。
