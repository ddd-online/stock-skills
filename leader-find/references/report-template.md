# 龙头扫描报告模板（leader-find）

> 用途：leader-find 生成 report/龙头扫描/YYYY-MM-DD-{{板块名}}.md 的固定骨架。节名、表头、列顺序照抄不改写、不调序；「板块定位与口径」「板块行情与阶段」「板块龙头认定」「人气龙头四查表」「行业龙头表」「结论」六节是次日回看与跟踪的入口，改名或调序会让历史报告对不上。一次只分析一个板块，同一天分析多个板块就各写一份报告。

## 使用说明（生成报告前删除本节）

- **板块参数必传**：没有板块名或 BK 代码就不生成报告，先向用户索取；板块名用 fetch_sector_boards.py --search <关键词> 定位 BK 代码与类型，定位不到时报错，不臆造代码。
- 数据来源：全部经 $market-data 获取（板块行情榜 / 板块成分股榜 / 板块财务排名 / 涨停池明细 / 个股行情日K·MA / 新闻公告 / 资金流向），不自行取数、不复制取数实现。
- 报告文件名含板块名：report/龙头扫描/YYYY-MM-DD-{{板块名}}.md；同日同板块重跑覆盖更新并注明运行时间。
- 本 SKILL 不读取工作区文件（ACCOUNT.md / POSITION.md / MUST.md / stocks/），报告里不出现账户、持仓与仓位内容。
- **当日单日口径**：本 SKILL 不读历史报告，不给「本轮第 N 天」，也不做资金「今日 vs 基准日」的方向对比；该节写「转 $limit-lifecycle」。
- **龙头认定跟着阶段走**：点火档（全是首板）写「无龙头」，最多标「先动股」，不写「龙头候选」；龙头候选只在扩散档出现（2–3 板晋级股）；龙头要等加速档才写「已确认」并给带动性数字；收缩档必写断板后四种走法。
- 龙头排序按五字段固定顺序：① 首封时间 → ② 连板高度 → ③ 换手与量能 → ④ 资金 → ⑤ 炸板后的回封速度；四种伪龙头（跟风板、尾盘偷袭板、高位高换手板、独涨板）标类型降级，不占龙头位。
- `{{...}}` 为待填字段，一律替换为真实数字或「未获取」；接口拉不到就写「未获取」，不填 0、不脑补。当天没有内容的行直接删掉，但小节标题保留，没有内容写「无」或「不适用」。
- 「最强」与「值得买」必须在结论区**分开列**；本 SKILL 不出买卖动作、不写买点止损、不给仓位建议。
- 模板中的「附：填充示例」与本节只供对照格式，不写进报告；报告正文从标题行开始。
