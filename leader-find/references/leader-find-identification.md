# 龙头识别细则

用途：leader-find 认定龙头、打分、复核与写报告时的判定细则。所有“数字依据”必须来自 $market-data 的真实报告并标注数据日期；输出不构成投资建议。

## 1. 两种龙头，先分清要哪种

| | 行业龙头（真龙头） | 人气龙头（板块最强） |
|---|---|---|
| 靠什么当选 | 营收、净利润、市占率行业第一梯队 | 板块启动后最先动、最能带动板块、回调最抗跌 |
| 时间维度 | 以年计 | 几天到几周 |
| 风险 | 便宜时没人理、可能长期不涨 | 高位巨量就是派发，接棒亏损巨大 |
| 对应识别 | 行业地位框架（见第 3 节） | 阶段 + 五字段纵向比较 + 四查框架（见第 2、4 节） |
| 对资金量的建议（默认口径） | 低价细分龙头或龙头指数（ETF） | 只用极小仓位 + 严格触发条件，或先模拟 |

“人气龙头”无官方定义，为经验性框架；“行业龙头”是基本面概念。两条路风险等级完全不同，不要混着说。

## 2. 板块龙头认定（与 $limit-lifecycle 同口径）

先认阶段，再认龙头：**龙头不是涨得最多的那只**，而是最先动、能带动板块、板块回调时最抗跌的那只。同板块比较不看名气与股价，也不打总分，只按下面两件事走：先看阶段决定“有没有龙头”，再按五字段排序决定“谁是”。本 SKILL 是**当日单日口径**（不读历史报告）；本轮第 N 天、资金两时点方向与三检查点体检由 $limit-lifecycle 给。

### 2.1 阶段 → 有没有龙头

阶段判定（三维：涨停结构 / 龙头状态 / 资金与量能，顺序固定：收缩 → 加速 → 扩散 → 点火）见第 2.4 节的判定表与 $limit-lifecycle 速查表；落好阶段后按下表写龙头：

| 阶段 | 有没有龙头 | 判据（数字） | 报告里怎么写 |
|---|---|---|---|
| 点火 | 一般没有 | 板块内全是首板（无 2 板及以上）；8 家首板也照样是没有龙头 | 写「无龙头（全是首板）」；最多标「先动股：{{名称}}（首封 {{时间}}）」，**不写「龙头候选」**，等次日看谁先连板 |
| 扩散 | 有龙头候选 | 板块内出现 2–3 板晋级股，逐个点名（名称 + 板数） | 晋级股全部列为「龙头候选」，按五字段排序：第一名写「龙头候选（首选）」，其余写「龙头候选」 |
| 加速 | 有龙头（已确认） | 龙头 ≥4 板（或板块内 ≥2 只三板及以上）**且板块跟涨**：板块指数当日涨幅为正、涨停家数占全场 ≥15%、板块内涨停股平均换手 ≥20% | 写「龙头（已确认）：{{名称}} {{N}} 板」+ 带动性数字（首封时间、板块涨幅、家数占比） |
| 收缩 | 龙头断板/炸板/跌停 | 昨日最高板个股今日不在涨停池（炸板或跌停），或板块家数腰斩 + 资金净流出 | 按第 2.3 节四种走法写，并给动作 |

注：板块内一旦冒出 2 板及以上，按固定顺序就落「扩散」，龙头候选落在扩散档；点火档没有任何龙头候选。龙头地位**次日才确认**：候选次日仍封板且板块跟着走 → 升级为「龙头（已确认）」；次日断板 → 回到点火/收缩重新评。

### 2.2 五个排序字段（同板块内纵向比较，固定顺序）

| # | 字段 | 数据来源 | 强 | 弱 / 伪龙头信号 |
|---|---|---|---|---|
| 1 | 首封时间 | zt_rows.first_seal | 09:25 集合竞价封板、开盘秒板 | 11:00 之后才封；14:00 之后＝尾盘偷袭板 |
| 2 | 连板高度 | zt_rows.board_count | 板块内最高板，且与跟风股拉开档次 | 和跟风股一样高（都是首板）＝没有龙头 |
| 3 | 换手与量能 | zt_rows.turnover_pct | 放量突破、换手 5%–15% | 连板换手 ≥25%（高位高换手板）、或缩量滞涨 |
| 4 | 资金 | 板块行主力净流入 + fetch_capital_flow / fetch_sector_leaders（个股） | 板块主力净流入为正，个股有大单进场 | 板块资金净流出、只有它一只有量＝独涨板 |
| 5 | 炸板后的回封速度 | zt_rows.break_count / last_seal；收盘未封住在 zb_all_rows | 炸板后几分钟内回封、收盘仍封住 | 开板后越走越低、尾盘才勉强封、或进炸板池 |

读法：五个字段是**排序**用的，不是打分表——先按 1（谁先动）、再按 2（谁在上面），3–5 确认质量；字段 1 与 2 冲突（先动的不是最高板）时两只都留在候选里，把冲突写进理由。

### 2.3 四种伪龙头与断板后四种走法

四种伪龙头（识别到就降级，不占龙头/龙头候选位）：

| 类型 | 长什么样 | 识别方法 |
|---|---|---|
| 跟风板 | 龙头封板之后才涨停的同板块个股 | 看 first_seal：排在龙头之后的都是跟风，次日溢价通常明显低于龙头 |
| 尾盘偷袭板 | 14:00 之后才封板，或尾盘突然拉涨停 | first_seal ≥ 14:00 |
| 高位高换手板 | 连板但换手 ≥25% | turnover_pct（封板的钱随时可能撤） |
| 独涨板 | 只有它涨，板块其他票在跌 | 板块上涨家数 < 下跌家数、或主力净流出，属个股行为不是主线 |

伪龙头不等于「假的、会跌」——它们可能次日继续涨停；它们的意思是**没有带动性**，不能用「板块主线」的逻辑去解释和操作。

龙头断板后的四种走法：

| 走法 | 怎么识别 | 动作 |
|---|---|---|
| 换龙头 | 板块里冒出新的连板核心，涨停家数没有继续塌、资金仍在流入 | 主线身份改变：按新的票重新做阶段评估 |
| 龙头独活 | 龙头还封着，但板块家数腰斩、资金转负 | **按退潮处理**——看板块的家数与资金，不看龙头的脸色 |
| 板块退潮 | 龙头断板 + 跟风股集体下跌 + 资金净流出 | 整条线移出跟踪，等下一轮点火 |
| 反包 | 断板次日重新涨停收复失地 | 只观察、不参与：反包成功率低、节奏快 |

### 2.4 阶段判定表（当日单日口径）

| 阶段 | 涨停结构 | 龙头状态 | 资金与量能 |
|---|---|---|---|
| 点火 | 1–3 家涨停、多是首板；家数更多但全是首板也按点火记 | 没有 2 板及以上（无连板核心） | 小幅净流入，量能温和放大 |
| 扩散 | 涨停家数较昨日明显增加（默认 +≥2 家或 ≥50%） | **出现 2–3 板晋级股（决定性）** | 净流入为正，板块内涨停股换手 5%–15% |
| 加速 | 板块内多股连板、涨停家数占全场比重高（默认 ≥15%） | 龙头 ≥4 板，或 ≥2 只三板及以上 | 净流入最大，板块内涨停股平均换手 ≥20% |
| 收缩 | 涨停家数快速减少或归零，开始出现跌停 | 龙头断板、炸板或跌停 | 资金转为净流出 |

判定顺序固定：① 收缩 ② 加速（高度条件 + 量能条件同时满足）③ 扩散（决定性 = 出现 2–3 板晋级股）④ 点火（没有 2 板及以上）。单一板块的当日数据里若昨日家数缺失，把该格写“未获取”，不猜。

|---|---|---|---|---|
| 中晶科技（半导体） | 3 | 09:25:00 / 09:59:39 | 10.54 | 强：集合竞价封板、开板 34 分钟回封、换手温和 → 龙头候选（首选） |

## 3. 行业龙头：行业地位框架

1. **定义行业**：用行情软件的行业分类（东方财富行业/申万行业），不要凭题材自己拼一个“行业”。概念/题材板块不能直接当“行业”排名。
2. **规模排名**：行业内按营收、净利润排序，第一梯队 = 前 3 名（数据：fetch_sector_fundamentals 营收榜/净利榜；财务报告期与同比口径看表头）。
3. **质地四数字**（同行比）：毛利率高于同行；ROE 高且多年稳定（看多报告期，别只看一期）；负债率合理；经营现金流为正。
4. **估值**：PE/PB 跟同行比、跟自己历史比。龙头可以有溢价，但溢价到离谱 = “好公司坏价格”。
5. **验证主营**：该业务收入占比真实（最新财报主营构成 + 公告/新闻）。收入占比为 0 或被澄清“不相关/无收入”的“龙头”是伪龙头，一票否决。

不确定哪只是行业龙头时，龙头一篮子组合 = 指数基金/ETF，把“选龙头”外包给指数编制规则。行业龙头仍要过“好价格、好时机”——选公司管“买什么”，买点管“什么时候买”，两件事别混。

## 4. 人气龙头：相对强度框架

人气龙头不是“涨得最多的那只”，是板块里相对最强、还没到派发阶段的那只。先用第 2 节的五字段排出板块内顺序，再用四查（两两对比，不和感觉比）确认质量与可操作性：

| # | 检查项 | 合格标准 |
|---|---|---|
| 1 | 相对强度 | 板块启动时它先涨、涨得多；板块回调时它跌得少、先收复 |
| 2 | 硬逻辑占主营 | 题材收入写在财报主营里；澄清“无收入/不相关”= 一票否决 |
| 3 | 量能健康 | 上涨有量、回调缩量；换手 5%–10% 人气足但未过热；高位巨量、换手 >30% = 派发嫌疑 |
| 4 | 给上车点 | 连板不给机会就等第一次回踩（缩量回踩企稳/收复关键位），不在涨停板追 |

找法：板块内过候选池（默认：剔除 ST/新股，涨幅 ≥3%、换手 5–10%、流通市值 50–200 亿、上升趋势；用户说明的个人口径优先）→ 五字段排序 → 对候选两两做上表对比 → 留下相对最强的一只列入观察名单（写进报告，触发条件与预案写明，不落盘）。涨停/连板领涨股列“涨停候选”，默认无上车点。

两两对比示例写法：

| 对比项 | 候选A | 候选B | 谁强 |
|---|---|---|---|
| 首封时间 / 板数 | 09:25 封板、3 板 | 14:02 封板、3 板 | A（先动且高度相当） |
| 5日/10日涨幅 | +x%/+y% | +m%/+n% | A（数字差） |
| 题材主营占比 | 有/待核 | 澄清无收入 | B 一票否决 |
| 换手与量能 | 缩量回踩 | 高位巨量 | A |
| 上车点 | 回踩企稳位出现 | 涨停无点 | A（仍要等回踩确认） |
| 结论 | 板块相对最强 → 进观察名单 | 淘汰：硬逻辑不过 | — |

## 5. 最强 ≠ 值得买

同样的题材、同样的“强”，买在启动初段和买在连板末端是两个世界：

| | 等回踩/突破企稳买 | 情绪高潮追买 |
|---|---|---|
| 止损距离 | 近（关键位下方一点点） | 远（离启动位已 20%–50%） |
| 盈亏比 | 计划内，可算 | 上方空间小、下方空间大，常不足 1:1 |
| 容错 | 错了小亏离场 | 错了就是一根大阴线 + 次日跳空 |

结论：它强不强是筛选问题；你买不买、在哪买是纪律问题。最强没给上车点就让它过去——错过不是损失。

## 6. 龙头不豁免五关

任何“龙头”落到账户前都要过同一套关，一条都不能少；leader-find 只完成“识别/筛选”，五关分别由协作 SKILL 执行：

| 关 | 内容 | 由谁做 |
|---|---|---|
| 体检 | 基本面六数字 + 硬逻辑 + 避雷清单，不合格一票否决 | $stock-analysis |
| 买点 | 回踩企稳收阳 / 放量突破回踩不破，不追涨停 | $stock-analysis 给锚点 |
| 仓位 | 情绪属性票只给情绪票档位，总仓与现金红线不破 | $position-management |
| 止损 | 买前写好，破位即走，跳空破位不等收盘 | $position-management / 交易计划 |
| 复盘 | 每日预案表 + 平仓四层复盘 | $stock-analysis 持仓检查模式 / $position-management |

## 7. 一票否决与风险检查清单

- 名称含 ST / 退市整理 / 风险警示
- 上市 ≤5 日新股（名称 N/C 开头，无涨跌幅限制）
- 公告或新闻澄清题材“无收入、不相关、未量产”→ 硬逻辑证伪
- 高位巨量、换手 >30% → 派发嫌疑
- 财报主营收入占比为 0 的“行业龙头”（伪龙头）
- PE 为负 + PB 极高且无业绩支撑（基本面硬伤；技术面博弈须有明确纪律）
- 主力资金与价格背离（放量上涨但主力大幅净流出）

任一命中即不进名单；写报告时淘汰理由必须可核验（指向具体数据/新闻标题）。

## 8. 引用与免责

本细则为经验性框架，无官方背书；与用户明确说明的个人规则冲突时以用户规则为准。所有分析不构成投资建议，股市有风险，投资需谨慎。
