# 龙头扫描报告模板（find-leader）

> 用途：find-leader 生成 report/龙头扫描/YYYY-MM-DD.md 的固定骨架。节名、表头、列顺序照抄不改写、不调序；用户在后续追问（如「昨天扫到的龙头今天怎么样」「把最强和值得买分开」）时按同一套节名回看历史报告，改名或调序会让历史报告对不上。

## 使用说明（生成报告前删除本节）

- 数据来源：全部经 $market-data 获取（板块行情榜 / 板块成分股榜 / 板块财务排名 / 个股行情日K·MA / 新闻公告 / 资金流向），不自行取数、不复制取数实现。
- `{{...}}` 为待填字段，一律替换为真实数字或「未获取」；接口拉不到就写「未获取」，不填 0、不脑补。
- 当天没有内容的行直接删掉，不留空行；但每个小节标题保留，没有内容就写「无」或「不适用」。
- 所有数字标数据日期与口径来源；口径来源写清是本 SKILL 默认口径还是用户请求中说明的个人阈值。
- 本 SKILL 不读取工作区文件（ACCOUNT.md / POSITION.md / MUST.md / stocks/），报告里不出现账户、持仓与仓位内容。
- 「最强」与「值得买」必须在结论区**分开列**；本 SKILL 不出买卖动作、不写买点止损、不给仓位建议。
- 「模式与范围」写节奏按实际模式：全市场扫描才逐行写「活跃板块表」；指定板块模式在该节写「指定板块模式，跳过本表」，小节保留。
- 模板中的「附：填充示例」与本节只供对照格式，不写进报告；报告正文从标题行开始。
