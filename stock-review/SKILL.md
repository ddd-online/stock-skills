# 持仓检查与复盘

## 流程

1. 收集持仓信息（缺失就向用户询问，或明确标注“未提供”）：
   - 代码、买入价、手数、成本（含佣金）
   - 止损价、触发规则（默认“收盘跌破执行”）
   - 止盈价、时间止损（默认2周）
   - 买入理由
2. 拉取真实数据：

   ```bash
   python scripts/fetch_quote.py <代码> --days 30
   ```

3. 输出“持仓检查报告”（持仓期间使用）：
   - 数据表：现价、今日高/低、距止损/止盈（金额与%）、成交量、换手、MA5/10/20
   - 五条检查：①价格位置 ②量能 ③新信息（查不到标“未核实”）④买入理由是否成立 ⑤心态
   - 客观判断：是否触发规则（如“收盘价14.61 > 止损14.58 → 未触发，按计划持有”）
   - 禁止：建议挪止损、改止盈、加仓摊平
4. 输出“平仓复盘报告”（已卖出后使用）：
   - 实际盈亏：卖出净额（卖出价×股数−佣金−印花税−过户费） − 买入成本
   - 费用默认：佣金万2.5最低5元、印花税卖出0.05%、过户费0.01‰（按用户券商调整）
   - 复盘三问：①计划执行了吗 ②买入理由成立了吗 ③流程哪里改进
   - 滑点记录：实际成交价 vs 预设止损价，差额单列
5. 结尾：“基于截至<日期>的真实数据，不构成投资建议，最终决定由用户作出。”

## 硬性规则

- 客观判断触发与否：只说“触发/未触发”，不预测涨跌。
- 真实数据：脚本拉不到就报错，不编造现价。
- 不改规则：持仓期间不调整用户既定止损/止盈。
