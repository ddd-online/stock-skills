# 持仓检查

## 触发与前置条件

- 触发：用户请求检查某只持仓，或 $stock-report 午间/收盘复盘逐只调用。
- 前置：该股必须在 POSITION.md 持仓中；不在持仓时不执行每日检查，提示改用 $stock-analysis 分析。
- 依赖文件：POSITION.md（总览表 + 该股持仓明细小节）、MUST.md（个人交易风格与必守规则）、stocks/<股票名称-股票代码>/STOCK-REVIEW.md（交易计划与历史检查记录）。
- 交接：检查后回写该股持仓明细小节中的现价与浮动盈亏（标注数据日期），并在 STOCK-REVIEW.md「每日检查」表追加当日行（决定 + 明日预案一句话）；触发止损/止盈/时间止损时只给出平仓结论，实际卖出由用户在可交易时间执行；用户卖出后调用 $position-management 告知卖出价，由它完成平仓复盘与总结。

## 流程

1. 读取工作区上下文：先从工作区 POSITION.md 读取该股总览表行与持仓明细小节（代码、买入价/成本、手数、止损、触发规则、止盈、时间止损、买入理由），从 MUST.md 读取个人交易风格与必守规则（检查与结论必须遵守）；明细缺失字段可从 stocks/<股票名称-股票代码>/STOCK-REVIEW.md 的交易计划取。POSITION.md 缺失或未填写时，向用户询问或明确标注“未提供”。
2. 拉取真实数据：调用 $market-data 获取该股行情数据。

3. 输出“持仓检查报告”（固定三段，格式见下方「收盘复盘输出格式」）：
   - 数据表：现价、今日高/低、成交量/换手、MA5/10/20、距止损/止盈（金额与%）
   - 第三步 个股：日K形态、收盘价 vs 止损/止盈/时间止损、触发与否、买入理由、新信息与心态
   - 第四步 量价：放量/缩量 + 涨/跌 → 量价四句翻译
   - 第五步 明日预案：按预案行模板填一行（9:25 看什么 / 触发条件 / 动作 / 不许做什么）
   - 客观判断：是否触发规则（如“收盘价14.61 > 止损14.58 → 未触发，按计划持有”）
   - 禁止：建议挪止损、改止盈、加仓摊平
   - 把本次检查结果与明日预案写入 stocks/<股票名称-股票代码>/STOCK-REVIEW.md 的「每日检查」表：追加一行（“决定”列含客观判断与“明日预案：…”一句话），交易计划节不改写
   - 回写 POSITION.md：更新该股持仓明细小节中的现价与浮动盈亏（标注数据日期）；出现异动（接近/触发规则、建议平仓等）时在小节内追加一行“{{日期}} 备注：…”
   - 若触发（收盘跌破止损/跳空破位/止盈/时间止损）：结论为“建议平仓”，写明触发条件与建议动作；不代替用户下单（可能不在交易时段）。用户卖出后调用 $position-management 告知卖出价完成平仓总结；未触发则按计划持有
4. 结尾：“基于截至<日期>的真实数据，不构成投资建议，最终决定由用户作出。”

## 每日检查五条

用收盘价做判断，不盘中盯价。

| # | 检查项 | 看什么 |
|---|---|---|
| 1 | 价格位置 | 收盘价多少？离止损、止盈多远（金额与%）？ |
| 2 | 量能 | 放量还是缩量？和前些天比异常吗？ |
| 3 | 新信息 | 公告、行业、大盘有没有变化？查不到标“未核实” |
| 4 | 买入理由 | 当初为什么买？今天还成立吗？ |
| 5 | 心态 | 有没有冲动想改计划？为什么？ |

对应关系：检查 1（价格位置）→ 第三步个股；检查 2（量能）→ 第四步量价；检查 3–5（新信息/买入理由/心态）→ 第三步个股的补充行。

## 收盘复盘输出格式（个股/量价/预案）

按收盘复盘速查规范的第 3–5 步输出该股复盘结果，结构固定，数据用收盘全天数据（午间调用用盘中数据并注明时段）。输入仍按「每日检查五条」逐项核对，输出归入下面三段。不预测涨跌，只写“如果……就……”。

### 第三步 · 个股

- 日K与位置：开 {{开盘价}} / 高 {{最高价}} / 低 {{最低价}} / 收 {{收盘价}}（{{涨跌幅}}），{{形态一句（如“高开冲高回落长阴”“突破后缩量回踩收 MA5 上方”）}}；现价相对 MA5/MA10/MA20/MA60 {{之上/之下}}
- 对照规则：距止损 {{金额（%）}}、距止盈 {{金额（%）}}、时间止损 {{日期}}；触发判断 {{触发 / 未触发}}，如“收盘 7.21 > 止损 7.20 → 未触发，按计划持有”/“盘中最低 36.72 破 36.90 后收回 → 不触发”
- 买入理由：{{成立 / 部分成立 / 已破坏}}，{{依据}}；新信息：{{公告/新闻/大盘与行业变化，查不到标“未核实”}}；心态：{{有无冲动想改计划及原因}}

### 第四步 · 量价

- 量能：成交量 {{手}} / 换手 {{%}}，{{放量/缩量/平量}} {{上涨/下跌}}
- 翻译：{{放量上涨 = 真金白银承接，突破可信；放量下跌 = 有人大笔离场，警惕出货（高位放量触发铁律4：直接清仓）；缩量回调 = 卖压不大，上升结构里算健康；缩量上涨 = 跟风不足，涨得虚}}

### 第五步 · 明日预案

| 股票 | 9:25 看什么 | 触发条件 | 我的动作 | 不许做什么 |
|---|---|---|---|---|
| {{股票名}} | {{竞价是否低开 / 能否收复 {{价位}} 等}} | {{低开破 {{价位}} / 收复 {{价位}} / 反弹到 {{区间}} / 时间止损到期}} | {{开盘即走 / 按预案离场 / 继续持有}} | {{不临时挪止损、不追高、不加仓摊平、不找理由等反弹}} |

- 触发条件必须可检查（跌破某价 / 收复某价 / 低开破位），不许写“感觉”。
- 跳空破位/暴跌日不等收盘：9:25 竞价即执行；T+1 当天买入不能卖。
- 预案只引用用户已写规则（POSITION.md 触发规则、交易计划、MUST.md 禁区），不产生新建议；“不许做什么”写该股禁区。
- $stock-report 收盘版逐只汇总本输出为「三、收盘复盘」第 3–5 步。

## 触发规则

- 收盘价跌破止损 → 触发，离场
- 跳空低开直接跌破止损 / 暴跌日 → 不等收盘，破位即走
- 盘中插针（最低破、收盘守住）→ 不触发

判断输出：未触发 → 按计划持有，不动作；触发 → 按规则离场，不商量、不挪止损。

## 硬性规则

- 客观判断触发与否：只说“触发/未触发”，不预测涨跌；预案只写可检查的触发条件与动作。
- 收盘复盘三段输出：个股/量价/明日预案按「收盘复盘输出格式」固定结构输出，$stock-report 收盘版直接采用汇总。
- 持仓信息以 POSITION.md 为准：先读工作区 POSITION.md，缺失字段再向用户询问或标注“未提供”。
- 真实数据：$market-data 拿不到数据就明确报错，不编造现价。
- 不改规则：持仓期间不调整用户既定止损/止盈。
- 只给平仓结论不下单：触发平仓条件时只输出“建议平仓”，实际卖出由用户在可交易时间执行。
- 只追加不建档：STOCK-REVIEW.md 在执行本 SKILL 前已存在（含交易计划），本 SKILL 只在「每日检查」表追加一行（当日行含客观判断与“明日预案：…”一句话），不创建文件、不改写交易计划。
- 只做每日检查：平仓复盘、盈亏计算与 TRADE-SUMMARY.md 由 $position-management 负责，本 SKILL 不越权。
