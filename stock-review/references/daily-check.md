# 每日5分钟检查

用收盘价做判断，不盘中盯价。

| # | 检查项 | 看什么 |
|---|---|---|
| 1 | 价格位置 | 收盘价多少？离止损、止盈多远（金额与%）？ |
| 2 | 量能 | 放量还是缩量？和前些天比异常吗？ |
| 3 | 新信息 | 公告、行业、大盘有没有变化？查不到标“未核实” |
| 4 | 买入理由 | 当初为什么买？今天还成立吗？ |
| 5 | 心态 | 有没有冲动想改计划？为什么？ |

## 触发规则（默认）

- 收盘价跌破止损 → 触发，离场
- 跳空低开直接跌破止损 / 暴跌日 → 不等收盘，破位即走
- 盘中插针（最低破、收盘守住）→ 不触发

## 判断输出

- 未触发：按计划持有，不动作
- 触发：按规则离场，不商量、不挪止损
