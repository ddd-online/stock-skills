# 收盘复盘速查（收盘版五步规范）

> 收盘后 10–15 分钟，从大到小读盘，只输出一件东西：明天的预案表。复盘不预测涨跌，只把“如果……就……”写下来。
> 分工：第 1–2 步（大盘、板块）由本 SKILL（stock-report）在收盘版直接分析；第 3–5 步（个股、量价、预案）由 $stock-review 对每只持仓按同一规范输出，本 SKILL 汇总进「三、收盘复盘」。

## 五步复盘顺序

| 步骤 | 读什么 | 回答的问题 | 负责 |
|---|---|---|---|
| 1. 大盘 | 510300/上证收在 MA20 上还是下 | 正常 / 防守 / 观望档？ | stock-report |
| 2. 板块 | 涨幅榜前3、跌幅榜前3；我的题材排第几 | 钱在哪？题材启动/加速/退潮？ | stock-report |
| 3. 个股 | 持仓收盘价 vs 止损/止盈/时间止损；日K形态 | 触发了吗？理由还成立吗？ | stock-review（逐只） |
| 4. 量价 | 放量还是缩量，涨还是跌 | 今天的涨跌是真是假？ | stock-review（逐只） |
| 5. 预案 | 写明日预案行 | 明天做什么、不做什么？ | stock-review（逐只）→ stock-report 汇总 |

空仓时只做 1、2 步 + 观察池：空仓也是仓位。

## 大盘档位速查

| 状态 | 判据（用 510300/上证指数） | 档位 |
|---|---|---|
| 上升 | 价格在 MA20 上方，MA20 上行，高低点抬高 | 正常档 |
| 震荡 | 价格围绕 MA20 上下拉锯，高低点横盘 | 防守档（减半） |
| 下跌 | 价格在 MA20 下方，均线向下排列，高低点降低 | 观望档（不开新仓） |

- 切换纪律：状态切换要连续 3–5 天站稳/跌破关键均线确认，不因单日涨跌改档；判断错了靠规则兜底（止损兜底，错过就错过）。
- 档位含义（写进报告）：正常档可正常建仓/加仓；防守档仓位减半、只做稳健标的、暂停加仓；观望档不开新仓，持仓按止损纪律处理，只维护观察池。
- 数据：$market-data 拉 sh510300（沪深300ETF）与 sh000001（上证指数）收盘行情；指数或 MA 缺失时标注“未获取”，不编造档位。

## 板块怎么读

- 数据：本 SKILL 用 $market-data 强势股榜（fetch_strong_stocks.py，含行业字段）归纳当日强势方向；板块涨幅榜前3/跌幅榜前3若数据源无法提供，明确标注“板块榜单未获取”，不编造。
- 回答三个问题：今天的钱在哪个方向？我的持仓/观察池题材排第几？题材是启动、加速还是退潮（用连续 3 天排名变化 + 量能判断，拿不到依据不写阶段）？
- 只记录不追：板块涨停潮追最后一段通常是最后一棒；板块强 ≠ 个股强（板块涨 5% 它只涨 3% 是弱势，板块跌 2% 它涨 3% 才是强）。

## 量价四句（$stock-review 对每只持仓输出翻译）

- 放量上涨 = 真金白银承接，突破可信
- 放量下跌 = 有人大笔离场，警惕出货（铁律4：高位放量直接清仓）
- 缩量回调 = 卖压不大，上升结构里算健康
- 缩量上涨 = 跟风不足，涨得虚

## 明日预案行模板（$stock-review 逐只输出，本 SKILL 汇总成表）

| 股票 | 9:25 看什么 | 触发条件 | 我的动作 | 不许做什么 |
|---|---|---|---|---|
|  |  |  |  |  |

- 触发条件必须可检查（跌破某价 / 收复某价 / 低开破位），不许写“感觉”。
- “不许做什么”写禁区：不临时挪止损、不追高、不加仓摊平、不找理由等反弹。
- 跳空破位/暴跌日不等收盘：9:25 竞价即执行；T+1 当天买入不能卖。
- 预案只引用用户已写规则（POSITION.md 触发规则、STOCK-REVIEW.md 交易计划、MUST.md 禁区），不产生新建议。
