# 复盘速查（统一五步规范）

> 任意时间运行，先判盘中/盘外，再按同一套五步输出：大盘 → 板块 → 个股 → 量价 → 预案。盘中是快照，盘外是最近收盘；不预测涨跌，只写“如果……就……”。
> 分工：第 1–2 步（大盘、板块）由 stock-report 分析；第 3–5 步（个股、量价、预案）由 $stock-analysis 持仓检查模式逐只输出，stock-report 汇总。

## 时段与数据口径

| 大类 | 子类型 | 判定 | 数据口径 | 检查记录 |
|---|---|---|---|---|
| 盘中 | 连续竞价 | 9:30–11:30 或 13:00–15:00，行情日期=今天 | 当前快照；成交量未走完 | 不写 STOCK-REVIEW/POSITION |
| 盘外 | 午间休市 | 11:30–13:00，行情日期=今天 | 上午收盘快照 | 不写 |
| 盘外 | 盘前 | 9:30 前，行情日期<今天 | 上一交易日收盘 | 不写 |
| 盘外 | 盘后 | 15:00 后，行情日期=今天 | 当日收盘 | 写入每日检查与 POSITION |
| 盘外 | 非交易日/数据未更新 | 周末、节假日，或行情日期<今天且不是盘前 | 最近交易日收盘 | 不写 |
| 盘外 | 数据时间异常 | `quote.datetime` 晚于当前运行时间或明显滞后 | 标“数据时间异常/未获取”，不判断盘中 | 不写 |

- 以 `sh510300` / `sh000001` 的 `quote.datetime` 为数据时间基准；不能只按钟表时间认定盘中。
- 报告日期用运行日期，数据日期用行情日期；盘前报告不能覆盖上一交易日的收盘报告。
- 当前时间在 9:30–15:00 但行情日期不是今天：标“盘外·数据未更新”，不得写成盘中快照。
- 工作日 9:30 前且行情日期不是今天：按“盘前”处理；无法确认节假日时标“盘前/可能非交易日”。
- 15:00 后若行情时间仍早于 15:00：标“收盘数据可能未更新”，不把 14:xx 数据当收盘。
- `quote.datetime` 晚于当前运行时间：标“数据时间异常”，不使用未来数据推断盘中状态。

## 五步复盘顺序

| 步骤 | 读什么 | 回答的问题 | 负责 |
|---|---|---|---|
| 1. 大盘 | 510300/上证最新价或收盘价 vs MA20 | 正常 / 防守 / 观望档？ | stock-report |
| 2. 板块 | 强势/弱势方向前3；我的题材排第几 | 钱在哪？启动/加速/退潮？ | stock-report |
| 3. 个股 | 最新价/收盘价 vs 止损/止盈/时间止损；日K形态 | 触发了吗？理由还成立吗？ | stock-analysis 持仓检查模式（逐只） |
| 4. 量价 | 放量还是缩量，涨还是跌 | 涨跌是真是假？ | stock-analysis 持仓检查模式（逐只） |
| 5. 预案 | 下一观察点、触发条件、动作、禁区 | 下一步做什么、不做什么？ | stock-analysis 持仓检查模式（逐只）→ stock-report 汇总 |

空仓时第 3–5 步写“空仓，无个股检查”，仍保留大盘与板块。

## 大盘档位速查

| 状态 | 判据（用 510300/上证指数） | 档位 |
|---|---|---|
| 上升 | 价格在 MA20 上方，MA20 上行，高低点抬高 | 正常档 |
| 震荡 | 价格围绕 MA20 上下拉锯，高低点横盘 | 防守档（减半） |
| 下跌 | 价格在 MA20 下方，均线向下排列，高低点降低 | 观望档（不开新仓） |

- 切换纪律：状态切换要连续 3–5 天站稳/跌破关键均线确认，不因单日涨跌改档。
- 盘中只写“当前档位快照”；盘外写截至数据时间的档位（盘后=当日收盘，午间=上午收盘，盘前/非交易日=最近收盘），并标数据日期。
- 档位含义：正常档可正常建仓/加仓；防守档仓位减半、只做稳健标的、暂停加仓；观望档不开新仓，持仓按止损纪律处理。
- 数据：$market-data 拉 sh510300 与 sh000001 的最新行情；指数或 MA 缺失时标“未获取”，不编造档位。

## 板块怎么读

- 数据：$market-data 强势股榜/板块榜（含行业字段）归纳方向；盘中标“截至 HH:MM”，盘外标数据时间（盘后=收盘，午间=上午收盘，盘前/非交易日=最近收盘）。板块榜单无法提供时明确标“未获取”。
- 回答三个问题：钱在哪个方向？持仓题材排第几？题材是启动、加速还是退潮（用连续排名变化 + 量能判断，拿不到依据不写阶段）？
- 只记录不追：板块涨停潮追最后一段通常是最后一棒；板块强不等于个股强。

## 量价四句（$stock-analysis 持仓检查模式逐只输出翻译）

- 放量上涨 = 真金白银承接，突破可信
- 放量下跌 = 有人大笔离场，警惕出货（高位放量直接清仓）
- 缩量回调 = 卖压不大，上升结构里算健康
- 缩量上涨 = 跟风不足，涨得虚

盘中必须标“累计量能未走完”，不能把当前成交量当全天量；盘外才按全日量能判断。

## 预案表模板（$stock-analysis 持仓检查模式逐只输出，本 SKILL 汇总）

| 股票 | 下一观察点 | 触发条件 | 我的动作 | 不许做什么 |
|---|---|---|---|---|
|  |  |  |  |  |

- 盘中：下一观察点写“盘中关键价/收盘确认”；收盘确认型规则不提前给最终结论。
- 盘前/非交易日：下一观察点写“下一交易日 9:25”，使用最近收盘数据。
- 盘后：下一观察点写“下一交易日 9:25”，使用当日收盘数据。
- 触发条件必须可检查（跌破某价 / 收复某价 / 低开破位 / 时间止损到期），不许写“感觉”。
- 跳空破位/暴跌日不等收盘：9:25 竞价或破位时按既定计划执行；T+1 当天买入不能卖。
- 预案只引用用户已写规则（POSITION.md 触发规则、STOCK-REVIEW.md 交易计划、MUST.md 禁区），不产生新建议。
