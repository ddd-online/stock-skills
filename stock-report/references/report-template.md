# 股票每日复盘报告模板（统一五步）

> 用途：stock-report 在任意时间生成复盘正文。所有模式使用同一份骨架；盘中/盘外只改数据口径、触发结论和预案指向，不切换精简版/完整版。

## 使用说明（生成报告前删除本节）

- 报告日期 = 运行日期（Asia/Shanghai）；数据日期 = `quote.datetime` 对应的行情日期，两者可以不同。
- 在正文标题下写明：运行时间、时段大类（盘中/盘外）、子类型（连续竞价/午间休市/盘前/盘后/非交易日）、数据时间、数据日期。
- 数据来源：ACCOUNT.md / POSITION.md / stocks/<股票名称-股票代码>/STOCK-REVIEW.md；行情用 $market-data。
- 第 1–2 步（大盘/板块）由 stock-report 填写；第 3–5 步（个股/量价/预案）直接采用 $stock-analysis 持仓检查模式的规范输出，不二次改写。
- 盘中用“最新价/截至 HH:MM”，盘外用“收盘价/数据日期”；盘中成交量必须标“累计量能未走完”。
- 盘中触发判断标“临时状态/待收盘确认”；跳空破位或暴跌型规则按既定计划即时执行；盘外才写最终“触发/未触发”。
- `{{...}}` 为待填字段；没有内容的一行删除，不留空行。空仓时第 3–5 步写“空仓，无个股检查”，保留大盘与板块。
- 报告保存为 `report/股票每日复盘/YYYY-MM-DD.md`（运行日期）；同日重跑覆盖更新并记录本次运行时间。
- 有邮箱时同步发送，主题「股票每日复盘（YYYY-MM-DD HH:MM · 盘中/盘外）」；邮件正文即本报告正文。
