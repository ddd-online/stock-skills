# 题材生命周期判定细则

用途：limit-lifecycle 判阶段、做主线健康度体检、写报告与生成推荐时的速查。所有阈值均为默认经验值，用户明确说明的个人规则优先；所有数字必须来自 $limit-find 报告或 $market-data 的真实输出并标注数据日期；不构成投资建议。

一句话原则：阶段不是按板块名字分的，是按每天都在变的数字分的；同一条线昨天是扩散、今天可能已经加速末期，所以每个交易日都要重判一次。

## 1. 四阶段判定数字（按涨停结构 / 龙头状态 / 资金与量能三维看）

判阶段先按这三个维度填数字，再落标签：**涨停结构 / 龙头状态 / 资金与量能**。缺一项写“未获取”，不猜。

| 阶段 | 涨停结构 | 龙头状态 | 资金与量能 |
|---|---|---|---|
| 点火 | 1–3 家涨停、多是首板（家数更多但全是首板也按点火记，理由写「宽度已起、连板核心未出现」）；板块指数涨幅温和 | 刚冒头，还没有连板龙头（无 2 板及以上） | 小幅净流入，成交量温和放大 |
| 扩散 | 涨停家数较昨日明显增加（默认 +≥2 家或 ≥50%），产业链上下游一起动（涨停股覆盖 ≥2 个细分行业/概念，有消息/政策/业绩更好） | **出现 2–3 板核心票——决定性条件，龙头从这些股中诞生，逐个点名** | 净流入明显（为正），换手升到 5%–15% |
| 加速 | 板块内多股连板，涨停家数占全场比重高（默认 ≥15%） | 龙头 ≥4 板，或 ≥2 只三板及以上；常见一字或秒板 | 净流入最大，换手 ≥20%，成交额创阶段新高（时间线样本 ≥3 份时核验；不足时写“成交额样本不足”，以换手为准） |
| 收缩 | 涨停家数快速减少或归零，开始出现跌停 | 龙头断板、炸板（该封没封住）或直接跌停 | 资金转为净流出，缩量阴跌或放巨量下跌 |

**阶段标签只有这四个：点火 / 扩散 / 加速 / 收缩。** 不许加括号后缀（「扩散（收缩）」「扩散（首日）」）、不许自造档位（「无涨停」「阶段待确认」）；退化与不确定写进判断理由和三检查点结论，不改阶段标签。

“换手 ≥20%”指**板块内涨停股的平均换手**（用 fetch_limit_up.py --json 的 zt_rows.turnover_pct 取该板块涨停股均值），不是板块指数换手；板块成交额 “阶段新高” 指板块行情榜的成交额高于样本内前几日的最高值。

板块归属只按**代码求交**：涨停池的行业名是接口给的 4 字截断名（「汽车零部」「自动化设」「互联网电」），与板块行情榜的板块名（「汽车零部件」「互联网电商」）不能按名字比对；正确做法是取该板块 BK 代码的成分股代码集合，与 zt_rows / zb_all_rows / dt_rows / yesterday_performance.rows 按代码求交（实测：汽车零部件 BK0481 成分 276 只，今日涨停 8 家、昨日涨停 3 家、平均换手 8.2%、炸板 2 家）。

**扩散的证据链（判定时逐项给数字，缺项写“未获取”）**：

| 维度 | 决定性/辅助 | 默认口径 | 反例（不算扩散） |
|---|---|---|---|
| 龙头状态 | **决定性** | 板块内出现 2–3 板晋级股（点名个股 + 板数），龙头从它们中诞生 | 全是首板（无 2 板）→ 点火档；已到 ≥4 板 → 走加速档 |
| 涨停结构 | 辅助 | 较昨日明显增加（增加 ≥2 家或增幅 ≥50%），且覆盖 ≥2 个细分行业（上下游一起动） | 家数暴涨但全是首板；只有 1 个细分行业（单点行为） |
| 资金与量能 | 辅助 | 主力净流入为正；板块内涨停股换手 5%–15% | 净流入为负；换手 ≥20% 且高度 ≥4 板（属加速，不是扩散） |
| 延续性 | 辅助 | 5日与10日涨幅至少一个为正 | 两个都为负 → 阶段仍是扩散，理由写「延续性未确认（5日 X%、10日 Y%）」，且不进推荐 |

## 2. 判定顺序（固定，不可跳步）

先按第 1 节的三维（涨停结构 / 龙头状态 / 资金与量能）填数字，再按下面的固定顺序落标签；顺序的作用是先看生死、再看高度、最后看宽度与容错，不许挑对自己有利的那一维先说。

1. **收缩**：龙头断板/炸板/跌停（昨日最高板个股今日不在涨停池），或板块出现跌停且涨停家数较昨日减少，或主力净流入转负且涨停家数减少，或该线今日涨停 0 家（含昨日还有、今天归零）。
2. **加速**：高度条件（龙头 ≥4 板、板块内 ≥2 只三板及以上、或板块涨停家数占全场比重 ≥15%）**且**量能条件（板块内涨停股平均换手 ≥20%）。默认口径明确不含“成交额创阶段新高”：fetch_sector_boards 只给当日快照，没有历史成交额来源；成交额每天记进「阶段演变时间线」，样本 ≥3 份后作交叉印证写进理由，不足时写“成交额样本不足”。
3. **扩散**：**决定性条件是板块内出现 2–3 板晋级股**（逐个点名名称 + 板数；龙头从这些股中诞生）；**不看涨停家数是否过 5**。另报三项辅助证据的数字：① 涨停家数较昨日明显增加（默认增加 ≥2 家或增幅 ≥50%；家数暴涨但全是首板不算扩散，落第 4 条）；② 产业链上下游一起动（该板块涨停股覆盖 ≥2 个细分行业/概念，用成分股榜 industry 字段统计；只有 1 个细分行业记“单点行为，产业链未动”）；③ 主力净流入为正、板块内涨停股换手 5%–15% 为健康区（≥20% 且高度 ≥4 板走加速）。延续性：5日与10日至少一个为正（都为负 → 阶段仍写「扩散」，理由里写“延续性未确认（5日 X%、10日 Y%）”并注明不进推荐）。
4. **点火**：板块内没有 2 板及以上时才落这一档——全是首板即点火，不论家数是 1–3 家还是更多；家数多但全首板时在理由里写「宽度已起、连板核心未出现，尚未扩散」。
5. **兜底**：以上都不满足时，取该板块样本内最近一次的阶段（样本不足时按数字直判：有 2 板及以上 → 扩散，只有首板 → 点火），并把矛盾的数字写进理由；**不新增标签**。

冲突与覆盖规则：

| 情形 | 处理 |
|---|---|
| 主线健康度三检查点两格为负 | 阶段落「收缩」，理由写“三检查点两格负（哪两格）” |
| 三检查点一格为负或出现「弱」格（资金缩量、宽度收缩） | **阶段标签不变**（该是扩散还是扩散，该是加速还是加速），在理由与三检查点结论里写「收缩迹象：哪一格、数字」，结论写「继续跟踪但不作为主线」，不进推荐 |
| 三检查点出现「未知」格 | 阶段照数字写，结论写明未知格数与缺什么，不下“还活着”，也不进推荐 |
| 高度/资金仍在但涨停家数收缩、也够不上点火 | 走第 5 条兜底：取样本内最近一次阶段（不新增标签），把矛盾数字写进理由 |
| $limit-find 的板块活跃度标“转弱”而阶段数字仍指向扩散/加速 | 阶段标签不变，理由里写「与活跃度口径不一致：x 家 vs 昨 y 家、炸板率 z%」 |
| 板块昨日无涨停数据（分母缺失） | 家数变化写“未获取”，该格不计正负，不用 0 代替 |
| 报告里的板块只有名字、没有 BK 代码，或名称与板块行对不上 | 用 fetch_sector_boards.py --search <板块名> 定位 BK 代码，并在报告里注明“BK 代码为本次检索得到” |

本轮第 N 天：以 ≤5 份样本（当日 + 之前四份 limit-find 报告）内该板块**首次出现涨停（≥1 家）**那天为第 1 天连续计数；中途出现 0 家涨停视为本轮结束，之后再出现写「第 1 天（重启）」；样本不足五份时写实际份数。

## 3. 板块龙头认定（有没有龙头 / 谁是龙头）

用途：回答「这个板块里有没有龙头」。龙头不是涨得最多的那只，也不是股价最高或名气最大的那只，而是**最先动、能带动板块、板块回调时最抗跌**的那只。同板块比较只按下面五个字段的固定顺序看，不打分、不看名气与股价。

### 3.1 阶段 → 有没有龙头（先看阶段，再找人）

| 阶段 | 有没有龙头 | 判据（数字） | 报告里怎么写 |
|---|---|---|---|
| 点火 | 一般没有 | 板块内全是首板（无 2 板及以上）；8 家首板也照样是没有龙头 | 写「无龙头（全是首板）」；最多标「先动股：{{名称}}（首封 {{时间}}）」，**不写「龙头候选」**，等次日看谁先连板 |
| 扩散 | 有龙头候选 | 板块内出现 2–3 板晋级股，逐个点名（名称 + 板数） | 2–3 板晋级股全部列为「龙头候选」，按五字段排序：第一名写「龙头候选（首选）」，其余写「龙头候选」 |
| 加速 | 有龙头（已确认） | 龙头 ≥4 板（或板块内 ≥2 只三板及以上）**且板块跟涨**：板块指数当日涨幅为正、涨停家数占全场 ≥15%、板块内涨停股平均换手 ≥20% | 写「龙头（已确认）：{{名称}} {{N}} 板」+ 带动性数字（首封时间、板块涨幅、家数占比）；不用「龙头可能」这种含糊写法 |
| 收缩 | 龙头断板/炸板/跌停 | 昨日最高板个股今日不在涨停池（炸板或跌停），或板块家数腰斩 + 资金净流出 | 按第 3.4 节四种走法写：换龙头 / 龙头独活 / 板块退潮 / 反包，各自给动作 |

注：本 SKILL 口径下「点火」＝全是首板（无 2 板及以上），所以点火档没有龙头候选；一旦冒出 2 板及以上，按第 2 节顺序落「扩散」，龙头候选落在扩散档。龙头地位**次日才确认**：候选次日仍封板且板块跟着走 → 升级为「龙头（已确认）」；次日断板 → 回点火/收缩重新评。

### 3.2 五个排序字段（同板块内纵向比较，固定顺序）

| # | 字段 | 数据来源 | 强 | 弱 / 伪龙头信号 |
|---|---|---|---|---|
| 1 | 首封时间 | zt_rows.first_seal | 09:25 集合竞价封板、开盘秒板 | 11:00 之后才封；14:00 之后＝尾盘偷袭板 |
| 2 | 连板高度 | zt_rows.board_count | 板块内最高板，且与跟风股拉开档次 | 和跟风股一样高（都是首板）＝没有龙头 |
| 3 | 换手与量能 | zt_rows.turnover_pct | 放量突破、换手 5%–15% | 连板换手 ≥25%（高位高换手板）、或缩量滞涨 |
| 4 | 资金 | 板块行主力净流入 + fetch_capital_flow / fetch_sector_leaders（个股） | 板块主力净流入为正，个股有大单进场 | 板块资金净流出、只有它一只有量＝独涨板 |
| 5 | 炸板后的回封速度 | zt_rows.break_count / last_seal；收盘未封住在 zb_all_rows | 炸板后几分钟内回封、收盘仍封住 | 开板后越走越低、尾盘才勉强封、或进炸板池 |

读法：五个字段是**排序**用的，不是打分表——先按 1（谁先动）、再按 2（谁在上面）、再看 3–5 确认质量；字段 1 与 2 冲突时（先动的不是最高板），把两只都留在候选里，在理由里写清冲突。

### 3.3 四种伪龙头（识别到就降级，不占「龙头 / 龙头候选」位）

| 类型 | 长什么样 | 识别方法 |
|---|---|---|
| 跟风板 | 龙头封板之后才涨停的同板块个股 | 看 first_seal：排在龙头之后的都是跟风，次日溢价通常明显低于龙头 |
| 尾盘偷袭板 | 14:00 之后才封板，或尾盘突然拉涨停 | first_seal ≥ 14:00（案例：09-17 锡华科技 14:02:57） |
| 高位高换手板 | 连板但换手 ≥25% | turnover_pct（案例：09-17 锡华科技 33.89%）——封板的钱随时可能撤 |
| 独涨板 | 只有它涨，板块其他票在跌 | 板块上涨家数 < 下跌家数、或主力净流出，涨停属个股行为，不是主线 |

伪龙头不等于「假的、会跌」——它们可能次日继续涨停；它们的意思是**没有带动性**，不能用「板块主线」的逻辑去解释和操作。降级写法：角色列写「伪龙头（{{类型}}）」，理由里跟数字，不进推荐。

### 3.4 龙头断板之后的四种走法

| 走法 | 怎么识别 | 动作 |
|---|---|---|
| 换龙头 | 板块里冒出新的连板核心，涨停家数没有继续塌、资金仍在流入 | 主线身份改变：按新的票重新做点火/扩散评估 |
| 龙头独活 | 龙头还封着，但板块家数腰斩、资金转负 | **按退潮处理**——看板块的家数与资金，不看龙头的脸色 |
| 板块退潮 | 龙头断板 + 跟风股集体下跌 + 资金净流出 | 整条线移出观察池，等下一轮点火 |
| 反包 | 断板次日重新涨停收复失地 | 只观察、不参与：反包成功率低、节奏快，不是可操作机会 |

## 4. 主线健康度三检查点

每个板块三格，每格四种状态：**正 / 弱 / 负 / 未知**。铁律：**每一个「正」「弱」「负」都要指向一个可比数字（两个时点 + 数值）；指不出来就写「未知」，未知既不算正也不算负**。用未知撑出「三格全正」，等于用结论补证据。

| # | 检查点 | 正（跟数字） | 弱（跟数字） | 负（跟数字） | 未知 | 数据来源 |
|---|---|---|---|---|---|---|
| 1 | 龙头还在不在 | 昨日最高板个股今日仍在涨停池（写今日板数与首封时间；今日最高板 ≥ 昨日注明“高度在抬”） | 不设 | 昨日最高板个股今日炸板、跌停或断板 | 昨日无涨停股（没有可比龙头），或当日数据未获取 | 「连板高度与最高板」高标梯队表 + --json 的 zb_all_rows / dt_rows |
| 2 | 涨停家数是增是减 | 今日家数 ≥ 昨日 | 今日少于昨日，但减少幅度 <1/3 且无跌停 | 今日较昨日减少 ≥1/3，或板块出现跌停 | 昨日家数未获取 | 板块成分股代码集合 ∩ zt_rows / yesterday_performance.rows |
| 3 | 资金是进还是退 | 今日主力净流入 >0 且 ≥ 基准日 ×70%（放大或基本持平；基准日为负而今日为正＝转向流入） | 今日 >0 但 < 基准日 ×70%（流入但明显缩量） | 今日 ≤0（含由净流入转净流出） | 时间线里找不到任何更早的可比数值 | 板块行主力净流入（今日）+ 时间线里该板块最近一份有数值的报告（基准日） |

**第三格必须两个时点**：单日数值只能说明“今天是流入还是流出”（状态），不能说明“方向”。基准日 = 时间线里该板块最近一份有主力净流入数值的报告日期，优先前一交易日；前一交易日缺失时取更早的最近一天，并写「X 日数值缺失，属两日对比」。默认阈值 70%（缩量三成以上算「弱」），用户可覆盖。

**第三格取数与同源**：今日值取自 fetch_sector_boards.py（按名定位用 `--search 板块名 --sort flow`；东财板块接口不可用时脚本自动切腾讯备用源，主力净流入＝腾讯 zljlr，并在输出里标注数据源与口径）。接口失败先重试/切源，两源都失败才写「未获取」，不许一次拉不到就把资金格记「未知」。**今日与基准日必须同源同口径**：跨源（如今日腾讯口径 vs 基准日东财口径）不得直接算比例，该格记「未知」并注明「跨源不可比」；备用源下没有同名板块时，用脚本给出的最接近板块名并在报告里写明替代关系，或记「未知」，不得张冠李戴。

正例（把未知写成正的反面教材 → 正确写法）：风电设备今日主力 +2.61 亿、基准日 9/15 为 +11.57 亿（9/16 缺失）→ 2.61/11.57 = 23% < 70% → 记「**弱**：主力 +2.61 亿为正，但与 9/15 的 +11.57 亿相比明显缩量（9/16 数值缺失，属两日对比）」。不能写成「正：主力 +2.61 亿（昨日值未获取）」，也不能因为昨日值缺失就整格跳过。

综合结论（优先级：负 → 弱 → 未知 → 全正）：

| 三格结果 | 结论 | 报告里怎么写 |
|---|---|---|
| 负 ≥2 | 移出跟踪名单 | 阶段落「收缩」；写明哪两格为负，不推荐 |
| 负 =1 | 继续跟踪但不作为主线 | 标注收缩点（哪一格、数字）；阶段标签不变 |
| 负 =0 且 弱 ≥1 | 继续跟踪但不作为主线 | 按弱在哪格给一句（资金在退 / 宽度在缩）；阶段标签不变 |
| 负 =0、弱 =0 且 未知 ≥1 | 证据不足 | 写明哪几格未知、缺什么，不能判为“还活着”，也不能进推荐 |
| 三格全正 | 还活着 | 继续跟踪；可进推荐的条件是**阶段为扩散**（点火、加速、收缩都不进推荐） |

示例（2026-09-14 元件簇，数字取自当日报告）：龙头超声电子 6 天 4 板封住（正）、涨停家数 9→6 家减少（负）、PCB 概念主力 +43.85 亿（正）→ 一负：继续跟踪但不作为主线（收缩迹象：家数 9→6）；次日超声电子盘中涨停后炸板、换手 40.42%，收缩信号应验。

示例（风电设备，两正一弱）：龙头锡华科技 2 板 → 3 板（正）、涨停 1 → 2 家（正）、主力 +2.61 亿 vs 9/15 +11.57 亿（弱）→ 结论「宽度和高度在走、资金在退，继续跟踪但不作为主线」。

## 5. 阶段对应动作（报告里怎么写）

| 阶段 | 市场含义 | 本 SKILL 的输出 |
|---|---|---|
| 点火 | 谁都没看见的时候，钱最好赚也最容易假；全是首板、还没有连板核心 | **不进推荐**：写「列观察，连续跟踪 3 天，等确认（出现 2–3 板晋级股）后再评估」；观察条件写在报告里、不落盘 |
| 扩散 | 出现 2–3 板晋级股、产业链上下游一起动，资金有持续性 | **可进推荐**（需三格全正：无负、无弱、无未知，且 5日与10日至少一个为正；相对安全的介入窗口，仍要过 $stock-analysis 的体检与买点） |
| 加速 | 最热的时候也是离场窗口 | 不推荐：写「空仓不追；持有者按既有规则减仓」 |
| 收缩 | 龙头断板的第一天就是信号，反抽多为反抽 | 不推荐：写「移出跟踪，等下一轮点火」 |
| 扩散/加速阶段但出现「弱」格或一格负（收缩迹象） | 还有数字但已在收缩，次日容易应验 | 阶段标签不变，不推荐：写「只跟踪不新增，等三格回到全正或龙头创新高」 |
| 有「未知」格 | 证据不足 | 不推荐：写「证据不足：N 格未知（缺什么）」，不进候选 |

本 SKILL 不写“模拟盘/实盘动作”当作指令，只把阶段对应的纪律提示写进报告；具体买卖由 $stock-analysis → $position-management 决定。

## 6. 三个最常见的错误（写完报告自检一遍）

1. **把当天涨幅榜第一当买入信号**：板块涨幅、资金、涨停家数三项都第一，往往已是加速末期，不是起点。
2. **把收缩段的反抽当新一轮启动**：涨停家数回升、封板率修复看着像回暖，区别只在龙头是不是创新高；老题材反抽不成立。
3. **用“它还在涨”给自己壮胆**：盘中摸涨停不等于封住；换手是不会说谎的指标（板块内涨停股平均换手 ≥20% 属高位区，接近 40% 属派发嫌疑）。
4. **把「未获取」当正数**：一格没有可比数字就是「未知」，既不算正也不算负；单日的主力净流入只能说明状态，方向必须两个时点（今日 vs 基准日）。用未知撑出「三格全正」，等于用结论补证据。
