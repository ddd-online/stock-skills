# 平仓复盘（四层：事实 → 执行 → 判断 → 改进）+ 盈亏计算

## 实际盈亏

- 买入成本 = 买入价×股数 + 买入佣金
- 卖出净额 = 卖出价×股数 − 卖出佣金 − 印花税（卖出额×0.05%） − 过户费（卖出额×0.01‰）
- 盈亏 = 卖出净额 − 买入成本
- 佣金费率与最低佣金以 ACCOUNT.md 交易费用设置为准（默认万2.5、最低5元/笔）

## 滑点

- 滑点 = 实际成交价 − 预设价（止损/止盈）
- 暴跌/跳空日滑点常见；接受滑点，尽快成交比计较一两分重要

## 复盘四层（顺序不能乱）

1. 事实层：买卖价格、费用、盈亏、滑点是多少？→ 一张算得清的账
2. 执行层：计划里的每条规则执行了没有？→ 纪律得分（执行与判断分开记）
3. 判断层：当初的买入理由后来成立了吗？→ 能力对错
4. 改进层：流程哪里改？提炼哪条规则？→ 一条可落地规则（写回 TRADE-RULES.md，教训沉淀 NOTES.md）

原则：结果由市场决定，过程由自己决定；复盘只审判过程，不审判结果。

## 结论写法

- 纪律层面：执行胜利/失败
- 判断层面：理由是否成立
- 行动层面：一条可落地规则
