# 建仓计划卡与下单前检查

## 建仓计划卡（每笔填一份）

| 字段 | 填写 |
|---|---|
| 股票 / 代码 | |
| 买入价（买点） | 符合支撑企稳或突破回踩？ |
| 手数 / 股数 | 100股整数倍 |
| 一手金额 | 价格 × 100 |
| 买入成本 | 金额 + 佣金（费率与最低佣金以 ACCOUNT.md 交易费用设置为准） |
| 止损价 | 支撑位下方；触发规则（默认收盘跌破） |
| 最大亏损 |（买入价−止损价）× 股数 + 费用 |
| 最大亏损占实际可用资产% | 应≤单笔预算（ACCOUNT.md「资金规则」：实际可用资产 × 2%） |
| 止盈价 | 压力位附近 |
| 时间止损 | 如2周不涨就走 |
| 盈亏比 |（止盈−买入）÷（买入−止损），理想>1 |
| 买入理由 | 一句话，写清依据 |

## 下单前检查（缺一条不做）

1. 买点条件成立了吗（现价符合计划价位）？
2. 止损、止盈、时间止损都写下来了吗？
3. 最大亏损在预算内吗？
4. T+1 考虑了吗（当天买入不能卖）？
5. 费用（佣金/印花税/过户费）计入成本了吗？

## 示例（数值仅演示计算，实际可用资产与预算以 ACCOUNT.md 资金规则为准）

买点4.65、止损4.55、止盈4.90、1手（100股）：
- 买入成本 = 100×4.65 + 佣金5 = 470元
- 最大亏损 =（4.65−4.55）×100 + 买入费5 + 卖出费≈6 ≈ 16元
- 盈亏比 =（4.90−4.65）÷（4.65−4.55）= 2.5:1 ✓
- 预算校验：最大亏损 ≤ ACCOUNT.md「资金规则」的单笔预算 ✓
