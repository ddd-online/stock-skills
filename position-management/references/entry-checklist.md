# 建仓计划卡与下单前检查

## 建仓计划卡（每笔填一份）

| 字段 | 填写 |
|---|---|
| 股票 / 代码 | |
| 买入价（买点） | 符合支撑企稳或突破回踩？ |
| 手数 / 股数 | 100股整数倍 |
| 一手金额 | 价格 × 100 |
| 买入成本 | 金额 + 佣金（费率与最低佣金以 ACCOUNT.md 交易费用设置为准） |
| 止损价 | 支撑位下方；触发规则（默认收盘跌破） |
| 最大亏损 |（买入价−止损价）× 股数 + 费用 |
| 最大亏损占本金% | 应≤预算（默认2%） |
| 止盈价 | 压力位附近 |
| 时间止损 | 如2周不涨就走 |
| 盈亏比 |（止盈−买入）÷（买入−止损），理想>1 |
| 买入理由 | 一句话，写清依据 |

## 下单前检查（缺一条不做）

1. 买点条件成立了吗（现价符合计划价位）？
2. 止损、止盈、时间止损都写下来了吗？
3. 最大亏损在预算内吗？
4. 单只≤40%、加仓后总仓位≤70% 吗？
5. T+1 考虑了吗（当天买入不能卖）？
6. 费用（佣金/印花税/过户费）计入成本了吗？

## 示例（教学演示，不构成建议）

本金5000、预算2%（100元）；买点4.65、止损4.55、止盈4.90：
- 100份×4.65=465元 + 佣金5 = 470元
- 最大亏损 =（4.65−4.55）×100 + 5 + 卖出费≈6 ≈ 16元（0.32%）✓
- 单只仓位：470/5000≈9% ≤40% ✓
- 盈亏比 =（4.90−4.65）÷（4.65−4.55）= 2.5:1 ✓
