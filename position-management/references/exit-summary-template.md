# 清仓执行与平仓总结模板

## 触发情形表

| 情形 | 触发条件 | 动作 |
|---|---|---|
| 止损 | 收盘跌破止损价；跳空低开直接跌破 | 离场；跳空/暴跌日不等收盘 |
| 止盈 | 价格到达目标位 | 卖出落袋，新手一次全卖 |
| 时间止损 | 周期内（如2周）不涨 | 离场，机会成本到上限 |
| 理由破坏 | 支撑跌破、逻辑证伪 | 按止损规则处理 |

## 执行规则

- 触发即走，不商量、不挪止损
- 接受滑点：实际成交可能低于止损价，尽快成交优先
- T+1：当天买入不能卖，触发后下一个交易日处理

## 平仓总结（卖出后填）

| 字段 | 填写 |
|---|---|
| 卖出日期 / 价格 | |
| 卖出类型 | 止损 / 止盈 / 时间止损 |
| 买入成本 | 买入价×股数 + 买入佣金 |
| 卖出净额 | 卖出价×股数 − 佣金 − 印花税0.05% − 过户费0.01‰ |
| 实际盈亏 | 卖出净额 − 买入成本（金额与占本金%） |
| 滑点 | 实际成交价 − 预设价 |
| 计划执行了吗 | |
| 买入理由成立吗 | |
| 流程改进 | 一条，下次行动层面 |

## 复盘三问

1. 计划执行了吗？没执行的环节是什么原因？
2. 当初的买入理由后来成立了吗？判断对错，不和运气混在一起。
3. 流程哪里能改进？仓位、买点、止损缓冲、规则本身。
