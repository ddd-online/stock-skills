# 清仓执行与平仓总结模板（四层复盘 + 盈亏计算）

## 触发情形表

| 情形 | 触发条件 | 动作 |
|---|---|---|
| 止损 | 收盘跌破止损价；跳空低开直接跌破 | 离场；跳空/暴跌日不等收盘 |
| 止盈 | 价格到达目标位 | 卖出落袋，一次全卖 |
| 时间止损 | 周期内（如2周）不涨 | 离场，机会成本到上限 |
| 理由破坏 | 支撑跌破、逻辑证伪 | 按止损规则处理 |

## 执行规则

- 触发即走，不商量、不挪止损
- 接受滑点：实际成交可能低于止损价，尽快成交优先
- T+1：当天买入不能卖，触发后下一个交易日处理

## 盈亏计算

- 买入成本 = 买入价×股数 + 买入佣金
- 卖出净额 = 卖出价×股数 − 佣金 − 印花税（卖出额×0.05%） − 过户费（卖出额×0.01‰）
- 盈亏 = 卖出净额 − 买入成本（金额与占本金%）
- 滑点 = 实际成交价 − 预设价（止损/止盈）；暴跌/跳空日滑点常见，尽快成交优先
- 费用费率以 ACCOUNT.md 交易费用设置为准（默认万2.5、最低5元/笔并标注）

## 平仓复盘（四层，顺序不能乱）

原则：结果由市场决定，过程由自己决定；复盘只审判过程，不审判结果。

1. 事实层（先算账）：买卖价格、费用、盈亏、滑点是多少？→ 一张算得清的账
2. 执行层（查纪律）：逐条对照该股 STOCK-REVIEW.md「交易计划」与 TRADE-SUMMARY.md 逐笔记录，结合下单前六问，标注执行了没有，给出纪律得分；执行与判断分开记——止损做对了就是做对了，不因结果亏钱而否定
3. 判断层（判对错）：当初的买入理由后来成立了吗？判断对错，不和运气混在一起
4. 改进层（出规则）：流程哪里改？提炼至少一条可落地规则，写入 TRADE-SUMMARY.md「总结」（平仓复盘只写该文件，历史保留），关键教训沉淀 NOTES.md

结论写法：纪律层面=执行胜利/失败；判断层面=理由是否成立；行动层面=一条可落地规则。

## 四指标统计（每 5-10 笔结算一次，写入根目录 TRADE-STATS.md）

每笔清仓后把该笔记录填一行（日期/股票/方向/价格/盈亏/是否符合系统/违规说明）；攒够 5-10 笔后按 TRADE-STATS.md「公式速查」结算四指标（胜率/平均盈亏/期望值/最大回撤），判断系统是否有效、亏损在入场端还是出场端；下一步只改一条规则。
