# 清仓执行与平仓总结模板

## 触发情形表

| 情形 | 触发条件 | 动作 |
|---|---|---|
| 止损 | 收盘跌破止损价；跳空低开直接跌破 | 离场；跳空/暴跌日不等收盘 |
| 止盈 | 价格到达目标位 | 卖出落袋，一次全卖 |
| 时间止损 | 周期内（如2周）不涨 | 离场，机会成本到上限 |
| 理由破坏 | 支撑跌破、逻辑证伪 | 按止损规则处理 |

## 执行规则

- 触发即走，不商量、不挪止损
- 接受滑点：实际成交可能低于止损价，尽快成交优先
- T+1：当天买入不能卖，触发后下一个交易日处理

费用费率以 ACCOUNT.md 交易费用设置为准（默认：佣金万2.5、最低5元/笔；印花税卖出 0.05%；过户费 0.01‰）。

## 平仓复盘模板（四层：事实 → 执行 → 判断 → 改进，顺序不能乱）

### 1. 事实层（先算账）

| 字段 | 填写 |
|---|---|
| 卖出日期 / 价格 | |
| 卖出类型 | 止损 / 止盈 / 时间止损 |
| 买入成本 | 买入价×股数 + 买入佣金 |
| 卖出净额 | 卖出价×股数 − 佣金 − 印花税0.05% − 过户费0.01‰ |
| 实际盈亏 | 卖出净额 − 买入成本（金额与占本金%） |
| 滑点 | 实际成交价 − 预设价 |

### 2. 执行层（查纪律）

逐条对照该股 TRADE-RULES.md 的规则与下单前六问，标注每条执行了没有，给出纪律得分。执行与判断分开记：止损做对了就是做对了，不因结果亏钱而否定。

### 3. 判断层（判对错）

当初的买入理由后来成立了吗？判断对错，不和运气混在一起。

### 4. 改进层（出规则）

流程哪里改？提炼至少一条可落地规则，写回该股 TRADE-RULES.md（历史保留），关键教训沉淀 NOTES.md。
