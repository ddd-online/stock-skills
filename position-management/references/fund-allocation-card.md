# 资金调度卡（按实际账户填写）

建仓、加仓、减仓、空仓——每个动作都有触发条件和金额上限。金额按 ACCOUNT.md「资金规则」读取，不写死。

## 资金分区（由 position-management 从 ACCOUNT.md 动态计算）

| 分区 | 规则 | 我的金额 |
|---|---|---|
| 实际可用资产 | ACCOUNT.md「账户总览」：本金 + 总盈亏 − 累计支取 | （动态计算） |
| 现金储备 | 按 ACCOUNT.md「资金规则」（现金储备红线） | （动态计算） |
| 单笔预算 | 按 ACCOUNT.md「资金规则」（单笔预算及降档档位） | （动态计算） |
| 当前档位 | 正常 / 降档 / 金额减半（按 ACCOUNT.md「资金规则」） | |

口径：现金储备红线 = 实际可用资产 × 30%；单笔预算 = 实际可用资产 × 2%（连亏 2 笔降档 1%）。

## 四个动作

| 动作 | 触发条件 | 金额规则 | 记录位置 |
|---|---|---|---|
| 建仓 | 观察池触发条件出现 + 检查全过 | 第一批小仓（1手起），单笔预算内 | POSITION.md、ACCOUNT.md |
| 加仓 | 盈利 + 趋势确认（未破位） | 加仓后单笔亏损预算仍符合 ACCOUNT.md「资金规则」；止损只上移 | 更新 POSITION.md |
| 减仓 | 到第一压力位；或破位（跌破移动止损） | ≥2手卖一半；破位不犹豫；不足2手直接清仓 | 更新 POSITION.md |
| 空仓 | 无信号；买入理由破坏/止损/时间止损 | 现金全留 | POSITION.md（空仓）+ 清仓归档 |

## 降档与恢复

- 触发 ACCOUNT.md「资金规则」的降档条件（如连亏）时执行降档，档位写回 ACCOUNT.md。
- 账户回撤触发金额减半时按 ACCOUNT.md「资金规则」执行，直到统计确认系统有效。
- 恢复：连续按系统执行 2-3 笔后，先小仓位，再逐步恢复。

## 禁止动作

- 亏损摊平（越跌越买）
- 满仓单吊
- 情绪票加仓
- 回本前破例放大仓位
