# 加仓规则与额度计算

## 加仓条件（全部满足才考虑）

1. 现有持仓是盈利的（**禁止亏损摊平**）
2. 趋势延续：价格仍在支撑上方、未破位

## 额度计算

- 按单笔最大亏损预算倒推：可买股数 ≈ 最大亏损 ÷（加仓价 − 止损价）
- 上限：不超过可用现金（ACCOUNT.md 当前现金）
- 按一手金额（价格×100）换算成手数（向下取整）

## 加仓部分独立计划

加仓也按建仓标准写一份计划卡：买入价、止损、止盈、时间止损、最大亏损、盈亏比，全部独立计算。

## 加仓后的整体规则

- 重新确认整个仓位的止损止盈：止损可上移（保护利润），**不可下移**（扩大风险）
- 加仓后的盈亏平衡成本要重算，但决策依据是“条件是否成立”，不是“摊低成本”
- 若加仓后触发止损，按整仓规则执行，不区别对待

## 反例

持仓亏损10%时加仓摊低成本 → 违反条件1，禁止。正确做法：按计划止损，等新买点重新建仓。
