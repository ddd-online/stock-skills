# 四指标统计（胜率 · 平均盈亏 · 期望值 · 最大回撤）

单笔是彩票，统计才是系统。系统有没有效不看单笔，看长期期望：同样的规则重复很多次，平均每笔是赚是亏。

## 何时结算

- 每笔清仓后：把该笔记录填一行到工作区根目录 TRADE-STATS.md（日期 / 股票 / 方向 / 价格 / 盈亏 / 是否符合系统 / 违规说明）。
- 每 5-10 笔结算一次四个数字；样本太小别下结论，违规笔数单独标出（违规样本对统计没意义）。

## 四个数字与公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 胜率 | 盈利笔数 ÷ 总笔数 | 单独看没用，必须配盈亏比 |
| 平均盈利 / 平均亏损 | 盈利总和 ÷ 盈利笔数；亏损总和 ÷ 亏损笔数 | 实际盈亏比 = 平均盈利 ÷ 平均亏损 |
| 期望值 | 胜率 × 平均盈利 − (1 − 胜率) × 平均亏损 | 为正=系统有效；为负=系统在漏钱 |
| 最大回撤 | 账户从高点跌落的幅度（金额 / 占本金%） | 从 ACCOUNT.md 资金变化记录计算 |

## 结算时问三句

- 期望值为正吗？
- 最大回撤扛得住吗？
- 违规的笔数是不是在减少？

亏损来自入场端（选什么、何时买）还是出场端（止损/止盈执行）？端不同，改的方向不同。结论写进 TRADE-STATS.md 的结算区，一次只改一条规则（改参数/加条件/删掉），写回 NOTES.md，历史保留；个股级复盘规则随平仓复盘总结写入 TRADE-SUMMARY.md。

常见误区：只盯胜率——赢的次数多但赢小亏大，期望值仍可能为负。先按系统执行，再谈统计；3 笔全亏 ≠ 系统永远亏，3 笔全违规 ≠ 系统有效。
