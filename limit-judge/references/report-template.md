# 打板竞价评估报告模板（limit-judge）

> 用途：limit-judge 生成 report/涨停板评估/YYYY-MM-DD.md 的固定骨架。节名、表头、列顺序照抄不改写、不调序；「竞价明细」是全样本唯一复核来源（竞价清单运行结束即清理），绝不能省略样本行。

## 使用说明（生成报告前删除本节）

- 输入：$limit-find 上一份落盘报告 report/涨停板复盘/YYYY-MM-DD.md（涨停全名单、最高板、晋级率与炸板率、主线板块、阵型判定）；缺报告就说明原因结束，不拼凑样本。
- 数据：经 $market-data 的竞价数据报告（fetch_auction.py）取高开幅度、竞价成交额、昨日全天成交额、竞价量占比与分档；口径判定（竞价口径 / 非竞价口径）写在标题与规则检查里。
- 硬规则置顶：① 竞价量占比一律按「竞价成交额 ÷ 昨日全天成交额」；② 昨日最高板今天天地板或跌停 → 当天只观察。命中哪条就写在报告首行与结论区。
- `{{...}}` 替换为真实数字或「未获取」，不填 0、不脑补；样本缺行情时另列并注明只数。
- 阵型引用昨日报告时，**阵型标签必须连它那一行结构说明一起引**（崩在哪 + 抬在哪），只引标签会把“老题材崩塌 + 局部高度抬升”读成全市场崩塌；本 SKILL 不重新判定阵型。
- 可视化：数字进表格，竞价量占比分档与高开分布可加等宽条（如 ▉▉▉ 3 只）；结论用固定标记（只观察 / 可列入观察名单）；不用表情符号。
- 竞价清单（YYYY-MM-DD-竞价清单.txt）是临时文件，运行结束（含报错）必须清理；清理前全样本明细必须已写进本报告。
- 本模板的使用说明与填充示例不写进报告；报告正文从标题行开始。
