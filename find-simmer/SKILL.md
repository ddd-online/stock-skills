# 蓄力票扫描（find-simmer）

蓄力票的定义：**1 周到本月内一直在缓慢上涨**的股票。它有两种形态：

- A 型 · 回踩蓄力：此前从低点快速起来、冲到阶段高点后回落，回踩不破关键位并缩量企稳——高点之后的“整理蓄力”；
- B 型 · 缓涨蓄力：没有暴涨，靠自身强势沿均线小步慢涨，回调浅、量价健康。

前提条件（硬依赖）：**蓄力只有发生在强势板块里才有意义**。板块不是市场主线/强势方向时，个股很难维持缓涨趋势，回踩可能变成下跌。因此本 SKILL 第一步必须执行 $limit-up 挖出当日强势板块，再进板块筛选；跳过 $limit-up 直接全市场找票 = 未按流程执行。

## 触发与前置

- 触发：用户请求“找蓄力票 / 缓慢上涨的票 / 回踩蓄力 / 抗跌慢牛 / 有没有在蓄力的票”，或需要为强势板块补充“没涨完但没爆发”的候选时。
- 前置（必须按顺序）：
  1. $limit-up 可用并已执行——输出当日强势板块/主线（含板块代码、涨幅、涨停集中、资金与领涨股）；
  2. $market-data 可用（fetch_sector_leaders 板块成分股榜、fetch_quote 个股日K/MA、fetch_sector_boards 板块榜）；
  3. 工作区 MUST.md / NOTES.md 存在则读取（个人市值/换手/环境阈值优先），缺失标注“未提供”。
- 大盘环境：先经 $market-data 拉 sh000001 的日K与 MA20/MA60，判上升/震荡/下跌市，用于“抗跌适配”判断。
- 落盘：报告写入 report/蓄力票扫描-YYYY-MM-DD.md（report/ 不存在则创建；同日再次运行覆盖更新并注明运行时间）。
- 交接：本 SKILL 只“发现+筛选+写观察建议”，不输出买卖信号；是否值得买转 $stock-analysis，观察池写入由 $watchlist-review 处理，资金仓位走 $position-management。

## 默认筛选阈值（经验默认，MUST.md / 用户规则优先）

| 检查项 | A 型·回踩蓄力 | B 型·缓涨蓄力 |
|---|---|---|
| 形态来源 | 近20日曾明显上涨并创出阶段高点，随后回落 | 无暴涨，沿 MA5/MA10 小步上行 |
| 近5日累计 | ≥ -3%（企稳，允许小幅整理） | 0% ~ +10%（无单日爆发） |
| 近10日累计 | 从高点回落但未破位（回撤 ≤25%） | >0，且近10日最大回撤 ≤8% |
| 近20日累计 | 高点形成前涨过（>0 或由高点回落而来） | +3% ~ +30%（3% 以下视为横盘，不算缓涨） |
| 位置 | 距20日高点回撤 5%–25%；现价在 MA20 附近/上方，未破 MA60 | 现价在 MA20 与 MA60 上方 |
| 量能 | 回落段缩量（近5日均量低于冲高段） | 上涨有量、回调缩量，换手 2%–15% |
| 剔除 | ST/退市、N/C 新股、当日涨停或涨幅 ≥7%、换手 >25% | 同左 |

大盘适配（默认）：

- 上升市（指数在 MA20 上方且 MA20 上行或站上 MA60）：A、B 都按上述标准筛；
- 震荡市（指数围绕 MA20）：只保留近20日累计 >0、回撤浅的候选；
- 下跌市/指数在 MA20 下方：要求候选“抗跌”——近10日累计 ≥0，或个股近10日回撤 ≤ 指数近10日回撤 +3 个百分点，且未破 MA60；不符合的候选标注“环境不适配”并剔除。

## 流程

### 第一步：先执行 $limit-up 挖强势板块（不可跳过）

1. 调用 $limit-up 得到当日涨停板复盘与强势板块/主线结论；记录每个强势板块：板块代码（BKxxxx）、类型（行业/概念）、今日/5日涨幅、涨停家数、领涨股、主力净流入。
2. 强势板块不足或 $limit-up 结论为“无明确主线”时：停止筛选，报告写明“今日无强势板块，蓄力票扫描不成立（蓄力必须依托强势板块）”，不硬找。
3. 保留主线/强势板块 ≤5 个作为本 SKILL 的板块池（与涨停分布重叠的同一题材合并）。

### 第二步：板块成分股初筛

对每个强势板块经 $market-data 拉成分股榜：当日涨幅前 60 与近5日涨幅前 60 两份合并去重（具体脚本与参数由 $market-data 决定），合并后按默认阈值快筛：

- 剔除：ST/退市、名称 N/C 开头新股、当日涨停或涨幅 ≥7%、换手 >25%（过热）；
- 保留：近5日 >0、近10日或近20日符合 A/B 型区间、流通市值按 MUST（未给则不设限只标注）；
- 每板块保留 ≤6 只进入形态核验，其余进“备选名单”（报告附代码即可）。

### 第三步：大盘环境与个股形态核验

1. 大盘环境：经 $market-data 拉 sh000001 日K与 MA20/MA60，输出环境（上升/震荡/下跌）与指数近10日涨幅/回撤，作为抗跌基准。
2. 对初筛候选（每板块 ≤6、合计 ≤15）逐只经 $market-data 拉个股日K 40 根（含 MA5/10/20/60）与资金流向，按参考细则计算：近5/10/20日累计涨幅、距20日高点回撤、MA排列、上涨/下跌天数、近10日最大回撤、近5日量能相对前高段量能。
3. 分类判定：
   - A 型：存在阶段高点 + 回撤 5%–25% + 缩量企稳 + 未破 MA60；
   - B 型：缓涨（近20日 +3%–30%）+ MA5≥MA10≥MA20 + 回撤浅 + 上涨有量回调缩量；
   - 既不像 A 也不像 B 的（纯横盘、已破位、连板情绪票）→ 剔除并写原因。
4. 大盘适配复核（见默认阈值表），把“环境不适配”的候选剔除或降级到备选。

### 第四步：排序与产出

入选名单每板块 ≤3、全报告 ≤6 只，按“板块强度 × 形态健康度”排：

- 板块强度：板块今日/5日涨幅、涨停家数、资金（来自 $limit-up 输出）；
- 形态健康度：近10日回撤越小、缩量企稳越明确、MA 排列越顺的优先；
- 每只附“为什么是蓄力票”的一句话依据（数字），以及类型 A/B。

### 第五步：报告落盘

按“报告格式”生成正文，先写 report/蓄力票扫描-YYYY-MM-DD.md，再回复摘要与文件位置。

## 报告格式（固定）

1. 标题：蓄力票扫描 · YYYY-MM-DD（数据日期；运行时间 HH:MM）
2. 前提与数据源：$limit-up 输出的强势板块名单（板块代码/名称/今日%/5日%/涨停家数/领涨股）+ 大盘环境（指数位置、MA20/MA60、近10日涨跌）
3. 候选池摘要：各板块初筛保留/剔除数量
4. 入选蓄力票表：

   | 板块 | 类型 | 代码 | 名称 | 现价 | 近5日% | 近10日% | 近20日% | 距20日高回撤% | MA状态 | 换手% | 近10日最大回撤% | 主力净流入 | 环境适配 | 一句依据 |

5. 备选名单表（代码/名称/板块/未入选原因一句话）
6. 剔除说明：被剔除的代表性形态与原因（连板情绪票、破位、纯横盘、环境不适配）
7. 观察建议：对入选票给“继续跟踪条件”（如：放量突破前高视为启动、跌破 MA20/MA60 视为蓄力失败），实际进观察池由 $watchlist-review 执行
8. 结尾：“以上基于截至<数据日期>的真实数据，不构成投资建议，最终决定由用户作出。”

## 硬性规则

- 必须先执行 $limit-up：报告必须引用 $limit-up 输出的强势板块；未执行或输出“无明确主线”时不得进入筛选，写明原因结束。
- 蓄力必须依托强势板块：不在 $limit-up 强势板块名单里的股票不入选，哪怕形态再好。
- 数据必须真实：涨幅、MA、回撤、量能、资金全部来自 $market-data 报告并标数据日期；缺数据标“未获取”，不脑补。
- 阈值透明：每条筛选都注明用的是哪档默认阈值，MUST.md / 用户规则优先；同一报告内不混口径。
- 区分形态：连板/主升末段、纯横盘（近20日 <3%）、已破位的回撤都不是蓄力，不得混入 A/B 型。
- 抗跌要对比：下跌市里“抗跌”必须与大盘近10日涨跌/回撤对比出数字，不能只写“看起来没怎么跌”。
- 只发现不下单：本 SKILL 不给买卖信号、不写买点止损；买卖判断转 $stock-analysis → $position-management。
- 报告必落盘：先写 report/蓄力票扫描-YYYY-MM-DD.md，再回复摘要。
- 免责声明：报告结尾必须带“不构成投资建议”。
