# 蓄力票判定细则

用途：find-simmer 核验与写报告时的速查。所有阈值均为默认经验值，用户明确说明的个人规则优先；所有数字必须来自真实行情并标注数据日期；不构成投资建议。

## 1. 时间口径与指标计算

- 近N日累计涨幅 =（最新收盘 / N个交易日前的收盘 − 1）×100%（用前复权日K）。
- 距历史高点回撤 =（核验区间内最高收盘 − 最新收盘）/ 最高收盘 ×100%；A 型用它验证“一轮大跌”的深度（默认 ≥30%）。核验 K 线：A 型 fetch_quote --days 120 --json、B 型 --days 60 --json（JSON 返回全部 N 根，文本只展示最近 15 根）。
- 横盘平台：大跌结束后近20日不再创新低、高低价差收窄、重心缓升；平台下沿 = 横盘期最低收盘，破位创新低 = 蓄力失败。
- 近10日最大回撤 = 近10日内收盘从局部高点到局部低点的最大跌幅（逐日比较收盘）。
- MA 排列：MA5 ≥ MA10 ≥ MA20 = 多头顺排（允许接近相等）；现价与 MA20/MA60 的关系用价格/MA−1 表示。
- 量能对照：A 型看横盘期量能相对大跌段是否萎缩、有无温和放量试盘；B 型看上涨放量、回调缩量。
- 大盘环境：上升市 = 指数 > MA20 且 > MA60（或 MA20 上行）；下跌市 = 指数 < MA20；其余震荡市。

## 2. 形态速查

| 特征 | A 型·回踩蓄力（大跌后横盘） | B 型·缓涨蓄力 | 不是蓄力（剔除） |
|---|---|---|---|
| 涨法/来源 | 曾冲上高点、有过人气（历史涨停/连板或大波段上涨），随后经历一轮大跌 | 无暴涨，沿 MA5/MA10 慢涨 | 连板/一字/单日 >10% 的主升末段 |
| 当前状态 | 大跌后转入横盘：平台整理、重心缓升、不再创新低 | 缓涨趋势本身，回调浅 | 仍单边下跌未横盘；横盘破位创新低 |
| 近5日 | -3% ~ +6%（横盘内小幅波动） | 0% ~ +10% | 近5日继续大跌 |
| 近10日 | -3% ~ +10%，横盘平台未破 | >0，且近10日最大回撤 ≤8% | 平台破位创新低 |
| 近20日 | 横盘重心缓升：0 ~ +15%（单边下跌不算） | +3% ~ +30% | <0 单边下跌，或 >30% 过热 |
| 位置 | 自历史高点深度回撤（默认 ≥30%）后，现价处于低位横盘平台内（距平台内高点 ≤15%） | 现价在 MA20、MA60 上方 | 高位未深调、破位收不回 |
| 量能/人气 | 历史人气需核验（无法核实标“待核”，不硬判）；横盘缩量、偶有温和放量试盘，换手 2%–15% | 涨放量、回调缩量，换手 2%–15% | 高位巨量、换手 >25% |

A 型不是“浅回踩不破关键位”：它要求曾有人气的冲高 + 一轮大跌 + 大跌后的横盘。横盘本身就是蓄力，是再次爆发前的征兆，不代表马上要涨。

## 3. 大盘适配

- 上升市：A/B 都允许；
- 震荡市：A 型保留“横盘未破位”，B 型只保留近20日累计 >0、回撤浅的候选；
- 下跌市：A 型要求横盘平台不破、近10日不创新低；B 型要求近10日累计 ≥0，或个股近10日回撤 ≤ 指数近10日回撤 +3 个百分点，且未破 MA60，才算“抗跌合格”。

报告里每只入选票必须写环境适配依据，例如“下跌市中指数近10日 −4.2%，该股 +1.8%，抗跌合格”。

## 4. 观察条件模板（由 watchlist-review 落池时细化）

- A 型：放量突破横盘平台上沿（含试盘高点）= 再次启动信号；跌破平台下沿或创新低 = 蓄力失败。
- B 型：沿 MA10 上行、放量加速 = 可能进入主升（不再算蓄力）；跌破 MA20 且缩量未收回 = 缓涨结束。

## 5. 免责

以上为经验性判定框架，无官方背书；与用户明确说明的个人规则冲突时以用户规则为准。所有分析不构成投资建议，股市有风险，投资需谨慎。
