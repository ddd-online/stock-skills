# 蓄力票判定细则

用途：find-simmer 核验与写报告时的速查。所有阈值均为默认经验值，MUST.md / 用户规则优先；所有数字必须来自真实行情并标注数据日期；不构成投资建议。

## 1. 时间口径与指标计算

- 近N日累计涨幅 =（最新收盘 / N个交易日前的收盘 − 1）×100%（用前复权日K）。
- 距20日高点回撤 =（20日内最高收盘 − 最新收盘）/ 20日内最高收盘 ×100%。
- 近10日最大回撤 = 近10日内收盘从局部高点到局部低点的最大跌幅（逐日比较收盘）。
- MA 排列：MA5 ≥ MA10 ≥ MA20 = 多头顺排（允许接近相等）；现价与 MA20/MA60 的关系用价格/MA−1 表示。
- 量能对照：冲高段日均量（涨停或大涨日附近） vs 回落/整理段日均量；整理段量明显更低 = 缩量企稳。
- 大盘环境：上升市 = 指数 > MA20 且 > MA60（或 MA20 上行）；下跌市 = 指数 < MA20；其余震荡市。

## 2. 形态速查

| 特征 | A 型·回踩蓄力 | B 型·缓涨蓄力 | 不是蓄力（剔除） |
|---|---|---|---|
| 涨法 | 先有冲高/阶段高点，再回落 | 无暴涨，沿 MA5/MA10 慢涨 | 连板、一字、单日 >10% |
| 近5日 | ≥ -3%（企稳） | 0%–10% | 近5日继续大跌破位 |
| 近20日 | 高点前涨过（如 >0），回落回撤 5%–25% | +3%–+30% | <3%（横盘）或 >30%（过热） |
| 位置 | 现价在 MA20 附近/上方，不破 MA60 | 现价在 MA20、MA60 上方 | 破 MA60 且收不回 |
| 量能 | 回落缩量 | 涨放量、回调缩量 | 高位巨量、换手 >25% |

## 3. 大盘适配

- 上升市：A/B 都允许；
- 震荡市：只保留近20日累计 >0、回撤浅的候选；
- 下跌市：候选近10日累计 ≥0，或个股近10日回撤 ≤ 指数近10日回撤 +3 个百分点，且未破 MA60，才算“抗跌合格”。

报告里每只入选票必须写环境适配依据，例如“下跌市中指数近10日 −4.2%，该股 +1.8%，抗跌合格”。

## 4. 观察条件模板（由 watchlist-review 落池时细化）

- A 型：放量收复前高/突破整理平台 = 再启动信号；跌破 MA20 或 MA60 且收不回 = 蓄力失败。
- B 型：沿 MA10 上行、放量加速 = 可能进入主升（不再算蓄力）；跌破 MA20 且缩量未收回 = 缓涨结束。

## 5. 免责

以上为经验性判定框架，无官方背书；与 MUST.md / NOTES.md 冲突时以用户规则为准。所有分析不构成投资建议，股市有风险，投资需谨慎。
