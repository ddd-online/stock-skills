# 蓄力票扫描报告模板（find-simmer）

> 用途：find-simmer 生成 report/蓄力票扫描/YYYY-MM-DD.md 的固定骨架。节名、表头、列顺序照抄不改写、不调序；「前提与数据源」必须留在报告开头，因为整份报告成立与否取决于 $find-leader 是否给出强势板块。

## 使用说明（生成报告前删除本节）

- 先决条件：必须先执行 $find-leader 并引用其强势板块输出（板块代码/名称/今日%/5日%/10日%/上涨家数/领涨股/主力净流入）；未执行不得进入筛选。
- 数据来源：全部经 $market-data 获取（fetch_sector_leaders 板块成分股榜、fetch_quote 个股日K·MA、fetch_sector_boards 板块榜、fetch_capital_flow 资金流向），不自行取数、不复制取数实现。
- 板块权限：只读 ACCOUNT.md「板块权限」，并在报告中注明来源；未提供或未确认时按保守默认（仅主板可交易、ST 不交易）处理，注明「权限未提供，按默认处理」与因权限剔除的只数。除该节外不读取任何工作区文件。
- `{{...}}` 为待填字段，一律替换为真实数字或「未获取」；接口拉不到就写「未获取」，不填 0、不脑补。
- 当天没有内容的行直接删掉，不留空行；小节标题保留，没有内容写「无」或「不适用」。
- 所有数字标数据日期；每条筛选注明用的是哪一档阈值（本 SKILL 默认口径或用户请求说明的个人阈值）。
- 「今日无强势板块」时：报告只保留「前提与数据源」，写明「今日无强势板块，蓄力票扫描不成立（蓄力必须依托强势板块）」，其余小节写「不适用（无强势板块）」，不硬找。
- 模板中的「附：填充示例」与本节只供对照格式，不写进报告；报告正文从标题行开始。
